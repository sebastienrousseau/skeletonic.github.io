Accesibilitate — WCAG 2.2 în v2.0.0

Translation note (2026-04-30). v2.0.0 adds RTL support and a refreshed 2026 framework comparison. The English source is the canonical reference while these translations catch up. See https://skeletonic.io/about/ · https://skeletonic.io/components/ · https://skeletonic.io/benchmarks/.

Skeletonic Stylus v2.0.0 livrează conformitatea WCAG 2.2 ca comportament implicit, nu ca temă opțională. Această pagină documentează ce este integrat și ce mixin-uri poți activa opțional pentru un control mai fin.

Ce primești gratuit

WCAG 2.2 SC Ce face v2.0.0 Cum verifici
1.4.3 Contrast (Minim) — AA <code>--cl-primary</code> și <code>--cl-secondary</code> întunecate la ≥ 4,5:1 pe text alb în butoane / badge-uri / linkuri DevTools → verificator de contrast
1.4.11 Contrast non-text — AA Borduri formulare, butoane, badge-uri, toate ≥ 3:1 La fel
2.4.7 Focus vizibil — AA Fiecare element focalizabil are un inel <code>:focus-visible</code> (galben pe fundal întunecat, albastru pe fundal deschis) <code>Tab</code> prin orice pagină
2.4.11 Focus neobscurat — AA (nou în 2.2) Header-ul sticky are înălțime redusă + scroll-margin de focus <code>Tab</code> dincolo de header-ul sticky
2.5.8 Dimensiune țintă — AA (nou în 2.2) Butoane / linkuri: zonă de atingere ≥ 24×24 px CSS DevTools box model
1.4.12 Spațiere text — AA Toate elementele respectă suprascrierile utilizatorului pentru line-height / letter-spacing Suprascrie în DevTools

Mixin-uri Stylus pe care le poți activa

Dacă compilezi din sursă, următoarele mixin-uri sunt disponibile în <code>src/stylus/utilities/mixins.styl</code>:

Mixin Utilizare
<code>focus-ring()</code> Inel de focus cu contrast ridicat care respectă <code>:focus-visible</code>
<code>visually-hidden()</code> Text doar pentru screen reader care rămâne focalizabil
<code>skip-link()</code> Ancoră care devine vizibilă la focus
<code>reduced-motion()</code> Înfășoară orice bloc în <code>prefers-reduced-motion: no-preference</code>
<code>forced-colors()</code> Ajustări pentru modul High Contrast din Windows
<code>target-size(24px)</code> Adaugă padding oricărui element clickabil pentru o țintă minimă de atingere

Exemplu:

<code class="language-stylus">// Aplică un inel de focus puternic pe un buton personalizat .my-button focus-ring() target-size(28px) </code></pre> 
 
Helper-ul skip-link
 
Adaugă aceasta primul lucru în <code><body></code>:
 
<code class="language-html"><a href="#main-content" class="skip-link">Sari la conținutul principal</a> </code></pre> 
Clasa nu se află în stylesheet-ul principal (deci greutatea paginii nu crește); este un fragment de 4 linii pe care îl compui singur sau folosind mixin-ul inclus <code>skip-link()</code>. Acest site îl utilizează — focalizează pagina și apasă Tab pentru a-l vedea apărând în colțul din stânga sus.
 
 
Verificarea propriilor pagini
 
Biblioteca livrează un script <code>a11y-test.mjs</code> sub <code>scripts/</code> care rulează axe-core pe fiecare URL furnizat.
 
<code class="language-bash">node scripts/a11y-test.mjs https://example.com </code></pre> 
CI rulează acest script pe pagina showcase <code>dist/index.html</code> la fiecare push.
