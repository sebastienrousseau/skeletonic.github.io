無障礙——v2.0.0 中的 WCAG 2.2

Translation note (2026-04-30). v2.0.0 adds RTL support and a refreshed 2026 framework comparison. The English source is the canonical reference while these translations catch up. See https://skeletonic.io/about/ · https://skeletonic.io/components/ · https://skeletonic.io/benchmarks/.

Skeletonic Stylus v2.0.0 將 WCAG 2.2 合規性作為預設行為，而非可選主題。 本頁記錄了內建功能以及可選啟用的 mixin。

免費獲得的功能

WCAG 2.2 成功準則 v2.0.0 的做法 驗證方式
1.4.3 對比度（最低）— AA <code>--cl-primary</code> 和 <code>--cl-secondary</code> 加深至白色背景上 ≥ 4.5:1 開發者工具 → 對比度檢查器
1.4.11 非文字對比度 — AA 表單邊框、按鈕、徽章均 ≥ 3:1 同上
2.4.7 焦點可見 — AA 每個可聚焦元素均有 <code>:focus-visible</code> 焦點環（深色背景為黃色，淺色背景為藍色） 在任意頁面按 <code>Tab</code> 鍵
2.4.11 焦點不被遮蔽 — AA（2.2 新增） 固定頁首高度縮減 + 焦點 scroll-margin 按 <code>Tab</code> 鍵越過固定頁首
2.5.8 目標大小 — AA（2.2 新增） 按鈕/連結：≥ 24×24 CSS px 點擊區域 開發者工具盒模型
1.4.12 文字間距 — AA 所有元素支援使用者自訂的 line-height / letter-spacing 在開發者工具中覆寫
2.3.3 互動動畫 — AAA 所有動畫類別包裹在 <code>@media (prefers-reduced-motion: no-preference)</code> 中 作業系統級減少動態效果
1.4.10 內容重排 — AA 版面在 320 px 寬度下無水平捲動 開發者工具窄視窗
深色模式 <code>prefers-color-scheme: dark</code> 自動切換 token 作業系統深色模式切換

可選啟用的 Stylus mixins

如果您從原始碼編譯，以下 mixin 可在 <code>src/stylus/utilities/mixins.styl</code> 中使用：

Mixin 用途
<code>focus-ring()</code> 支援 <code>:focus-visible</code> 的高對比度焦點環
<code>visually-hidden()</code> 僅供螢幕閱讀器的文字，保持可聚焦
<code>skip-link()</code> 聚焦時可見的錨點
<code>reduced-motion()</code> 將任意區塊包裹在 <code>prefers-reduced-motion: no-preference</code> 中
<code>forced-colors()</code> 針對 Windows 高對比模式的調整
<code>target-size(24px)</code> 將任何可點擊元素填充至最小觸控目標

範例：

<code class="language-stylus">// 在自訂按鈕上應用強焦點環 .my-button focus-ring() target-size(28px) </code></pre> 
 
跳轉連結輔助
 
將以下程式碼放在 <code><body></code> 內的第一個位置：
 
<code class="language-html"><a href="#main-content" class="skip-link">跳至主要內容</a> </code></pre> 
此類別不在核心樣式表中（因此頁面大小不會增加）；它是一個 4 行的片段，您可以自行編寫或使用內建的 <code>skip-link()</code> mixin。本站即使用了它——聚焦頁面並按 Tab 鍵即可看到它出現在左上角。
 
 
驗證您自己的頁面
 
函式庫在 <code>scripts/</code> 下隨附一個 <code>a11y-test.mjs</code> 腳本，可對您提供的每個 URL 執行 axe-core。
 
<code class="language-bash">node scripts/a11y-test.mjs https://example.com </code></pre> 
CI 在每次推送時都會對 <code>dist/index.html</code> 展示頁面執行此腳本。
