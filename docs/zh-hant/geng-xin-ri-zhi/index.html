v2.0.0 — 2026-04（當前版本）

「發行就緒」審查：無障礙、供應鏈、儲存庫整理。

無障礙（WCAG 2.2）

  • <code>$primary</code> 加深至 <code>hsl(210, 100%, 42%)</code>，使按鈕/徽章/連結中的白色文字達到 AA 對比度。
  • <code>$secondary</code> 加深至 <code>hsl(195, 100%, 33%)</code>。
  • 為每個互動元素添加 focus-visible 焦點環。
  • 在動畫模組中添加 <code>@media (prefers-reduced-motion)</code> 包裹。
  • 添加 <code>prefers-color-scheme: dark</code> token 切換。
  • 添加 target-size(24px) mixin 以滿足 WCAG 2.2 SC 2.5.8。
  • 添加 focus-not-obscured scroll-margin 輔助，用於固定頁首。

建置與供應鏈

  • 級聯層 — 每個區塊現在都位於 <code>@layer skeletonic.{reset,tokens,layout,elements,components,utilities}</code> 中。
  • CycloneDX SBOM 作為 npm 壓縮檔的一部分生成。
  • <code>size-limit</code> 預算在 CI 中強制執行：核心樣式表 8 KB gzip 上限。
  • CVE-2023-44270（postcss 換行解析）透過 <code>pnpm.overrides</code> 修補。
  • npm 發佈工作流程啟用來源驗證與簽署（<code>--provenance --access public</code>）。
  • 從 lint 設定中移除已歸檔的 <code>stylelint-a11y</code> 外掛。

儲存庫整理與消費者套件

  • 移除舊版 <code>package/</code> 目錄；<code>dist/</code> 現在是消費者的唯一真實來源。
  • README 重寫以反映 v2.0.0 安裝路徑。
  • <code>dist/</code> 已提交；<code>debug/</code> 為生成目錄且已加入 gitignore。
  • 新的 <code>.github/workflows/npm-publish.yml</code> 由標籤驅動。

錯誤修正（P0）

  • <code>row $:after</code> 父選擇器回歸 — 將 <code>src/stylus/components/_grid.styl</code> 中的雜散 <code>$</code> 替換為 <code>&</code>。
  • <code>.alternate</code> 錯誤地套用 <code>animation-direction: reverse</code> 而非 <code>alternate</code>。
  • <code>.alert-*</code> 命名空間化 — <code>.alert.success</code> → <code>.alert.alert-success</code>，避免與狀態類別衝突。
