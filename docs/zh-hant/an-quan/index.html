安全與供應鏈

效能

  • 壓縮後 38.8 KB · gzip 後 7.7 KB · brotli 後 6.7 KB（完整核心樣式表）。
  • 零 JavaScript — 純 Stylus → 純 CSS，零執行時間成本。
  • 級聯層架構 — 覆寫無需 <code>!important</code> 即可生效。
  • <code>size-limit</code> 預算 在 CI 每次提交時強制執行。

效能是一項安全控制。每少傳送一個位元組，就少了一個需要審計、簽署和驗證的位元組。

供應鏈摘要

控制措施 v2.0.0 狀態
CycloneDX SBOM 每次發行時生成，提交至 <code>dist/sbom.json</code>
npm 來源驗證 已啟用（<code>--provenance --access public</code>）
簽署的 git 標籤 由維護者金鑰 SSH 簽署
鎖定的 Dependabot 每週更新，自動審核
大小預算 <code>size-limit</code> 8 KB gzip 上限，回歸時 CI 失敗
Lint 每次推送時執行 <code>stylelint</code> + 無障礙斷言
CodeQL 已啟用，涵蓋 <code>javascript</code> 和設定檔
CVE-2023-44270 已修補，透過 <code>pnpm.overrides</code> 清除 <code>postcss@7</code>

CycloneDX SBOM

每個發佈的壓縮檔均包含一份 CycloneDX SBOM，位於 <code>dist/sbom.json</code>。您可以使用以下命令驗證新安裝的套件：

<code class="language-bash">pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0 jq '.metadata.component.version' \  node_modules/@sebastienrousseau/skeletonic-stylus/dist/sbom.json # → "2.0.0" </code></pre> 
SBOM 在發佈工作流程中由 <code>cyclonedx-npm</code> 生成。
 
 
npm 來源驗證
 
發佈的產物使用 npm 套件來源驗證 進行簽署。
 
安裝後可使用以下命令驗證：
 
<code class="language-bash">npm view @sebastienrousseau/skeletonic-stylus@3.0.0 --json | \  jq '.dist."npm-signature"' </code></pre> 
簽署的證明將壓縮檔追溯至產生它的確切 GitHub Actions 執行。
 
 
已知 CVE 與修補
 
  
 CVE 嚴重程度 狀態 
   
 CVE-2023-44270（postcss 換行解析） 中等 已修補，v2.0.0 透過 <code>pnpm.overrides</code> 將 <code>postcss</code> 升級至 ≥ 8.4.31 
  
 
Snyk 安全通報資料庫和 GitHub Security Advisories 動態受到持續監控；安全修補以修訂版本形式發佈。
 
 
報告漏洞
 
請不要為安全報告開啟公開的 GitHub issue。請改用以下私密通道：
 
 
github.com/sebastienrousseau/skeletonic-stylus/security/advisories/new
 
 
報告在 72 小時內得到確認，中等問題在 14 天內修復，嚴重問題在 48 小時內修復。
