v2.0.0 — 2026-04 (ปัจจุบัน)

รอบ "ความพร้อมเผยแพร่": a11y, supply chain, ความเป็นระเบียบของ repo

การเข้าถึง (WCAG 2.2)

  • <code>$primary</code> ทำให้เข้มขึ้น เป็น <code>hsl(210, 100%, 42%)</code> สำหรับคอนทราสต์ AA กับข้อความสีขาวในปุ่ม / ป้ายกำกับ / ลิงก์
  • <code>$secondary</code> ทำให้เข้มขึ้น เป็น <code>hsl(195, 100%, 33%)</code>
  • เพิ่ม วงแหวน focus-visible บนทุกอิลิเมนต์แบบโต้ตอบ
  • เพิ่ม <code>@media (prefers-reduced-motion)</code> ครอบโมดูลแอนิเมชัน
  • เพิ่ม <code>prefers-color-scheme: dark</code> การสลับโทเค็น
  • เพิ่ม mixin target-size(24px) เพื่อรองรับ WCAG 2.2 SC 2.5.8
  • เพิ่ม ตัวช่วย scroll-margin สำหรับ focus-not-obscured สำหรับส่วนหัว sticky

Build และ supply chain

  • Cascade layers — ทุกบล็อกอยู่ใน <code>@layer skeletonic.{reset,tokens,layout,elements,components,utilities}</code>
  • CycloneDX SBOM สร้างเป็นส่วนหนึ่งของ npm tarball
  • งบประมาณ <code>size-limit</code> บังคับใน CI: เพดาน 8 KB gzipped สำหรับ สไตล์ชีตหลัก
  • CVE-2023-44270 (postcss line return) แก้ไขผ่าน <code>pnpm.overrides</code>
  • Provenance + การลงนามใน npm publish workflow (<code>--provenance --access public</code>)
  • ลบปลั๊กอิน <code>stylelint-a11y</code> ที่ถูกเก็บถาวรออกจากการตั้งค่า lint

ความเป็นระเบียบของ repo และแพ็กเกจผู้บริโภค

  • ลบไดเรกทอรี <code>package/</code> แบบเก่า; <code>dist/</code> เป็นแหล่งข้อมูลเดียว สำหรับผู้บริโภค
  • เขียน README ใหม่ให้สะท้อนเส้นทางติดตั้ง v2.0.0
  • <code>dist/</code> ถูกคอมมิต; <code>debug/</code> ถูกสร้างและ gitignore
  • <code>.github/workflows/npm-publish.yml</code> ใหม่ขับเคลื่อนด้วยแท็ก

แก้ไขบั๊ก (P0)

  • regression <code>row $:after</code> ของ parent-selector — แทนที่ <code>$</code> ที่หลงเหลือ ด้วย <code>&</code> ใน <code>src/stylus/components/_grid.styl</code>
  • <code>.alternate</code> ตั้งค่า <code>animation-direction: reverse</code> แทนที่จะเป็น <code>alternate</code> โดยผิดพลาด
  • namespace <code>.alert-*</code> — <code>.alert.success</code> → <code>.alert.alert-success</code> เพื่อหลีกเลี่ยงการชนกับคลาสสถานะ
