Tokens — Skeletonic Stylus

This documentation is provided in English. A full translation is in progress. <!-- i18n-summary -->

Skeletonic exposes its design system as CSS custom properties on <code>:root</code>. Override any of them on any ancestor element to retheme that subtree at runtime — no Stylus recompile, no rebuild step.

<code class="language-css">.my-section { --cl-primary: oklch(0.55 0.20 280); /* purple */ --gr-h1: 3.6rem; } </code></pre> 
Every component that resolves these tokens through the cascade picks up the override automatically.
 
 
OKLCH since v2.0. Every brand, status, and grey token is defined in oklch() — perceptually uniform contrast, native wide-gamut (P3) support, and a single colour space that behaves the same way under <code>prefers-color-scheme: dark</code>.

Each colour has a paired background token (<code>--bg-primary</code>, <code>--bg-secondary</code>, …) for tinted surfaces.
 
Surface and text
 
  
 Token Light default Dark default 
   
 <code>--background-color</code> <code>#ffffff</code> <code>#0d0d10</code> 
 
 <code>--foreground-color</code> <code>#000000</code> <code>#f5f5f7</code> 
 
 <code>--focus-ring-color</code> <code>var(--link-color, #007aff)</code> <code>var(--link-color, #4ea1ff)</code> 
  
 
Dark values are applied automatically inside <code>@media (prefers-color-scheme: dark)</code>. <code>color-scheme: light dark</code> is declared on <code>:root</code> so native form controls and scrollbars also flip.
 
Greyscale (10 stops)
 
<code>--cl-grey-100</code> … <code>--cl-grey-1000</code> — single-hue ladder used for borders, shadows, neutral backgrounds.

The default scale uses a 1.27 (minor third) ratio — chosen for visual rhythm at every size, not for Φⁿ purity.

Golden-ratio constants
 
Used by the spacing scale, radius utilities, and wherever a "natural" proportion is needed.
 
  
 Token Value Purpose 
   
 <code>--gr</code> <code>1.62</code> Φ (the golden ratio) 
 
 <code>--gr-large</code> <code>0.62</code> 1/Φ 
 
 <code>--gr-medium</code> <code>0.50</code> midpoint of <code>gr-small</code> and <code>gr-large</code> 
 
 <code>--gr-small</code> <code>0.38</code> 1 − 1/Φ
