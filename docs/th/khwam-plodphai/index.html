ความปลอดภัยและ supply chain

ประสิทธิภาพ

  • 38.8 KB minified · 7.7 KB gzipped · 6.7 KB brotli สำหรับสไตล์ชีตหลักทั้งหมด
  • ไม่มี JavaScript — Stylus บริสุทธิ์ → CSS บริสุทธิ์ ไม่มีต้นทุน runtime
  • Cascade-layered — override ชนะโดยไม่ต้อง <code>!important</code>
  • งบประมาณ <code>size-limit</code> ถูกบังคับใน CI ทุกคอมมิต

ประสิทธิภาพเป็นมาตรการด้านความปลอดภัย ทุกไบต์ที่ไม่ส่งออกคือ ไบต์ที่ไม่ต้องตรวจสอบ ลงนาม และยืนยัน

สรุป supply chain

การควบคุม สถานะ v2.0.0
CycloneDX SBOM สร้างทุกรีลีส อยู่ภายใต้ <code>dist/sbom.json</code>
npm provenance เปิดใช้ (<code>--provenance --access public</code>)
แท็ก git ที่ลงนาม ลงนามด้วย SSH โดยผู้ดูแลหลัก
Dependabot ล็อกเวอร์ชัน อัปเดตรายสัปดาห์ ตรวจสอบอัตโนมัติ
งบประมาณขนาด <code>size-limit</code> เพดาน 8 KB gzipped ล้มเหลวใน CI เมื่อเกิน regression
Lint <code>stylelint</code> + การยืนยัน a11y ทุกครั้งที่ push
CodeQL เปิดใช้สำหรับ <code>javascript</code> และไฟล์ config
CVE-2023-44270 แก้ไขแล้ว ผ่าน <code>pnpm.overrides</code> ที่อัปเกรด <code>postcss@7</code>

CycloneDX SBOM

ทุก tarball ที่เผยแพร่รวม CycloneDX SBOM ที่ <code>dist/sbom.json</code> คุณสามารถตรวจสอบแพ็กเกจที่เพิ่งติดตั้งด้วย:

<code class="language-bash">pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0 jq '.metadata.component.version' \  node_modules/@sebastienrousseau/skeletonic-stylus/dist/sbom.json # → "2.0.0" </code></pre> 
SBOM ถูกสร้างด้วย <code>cyclonedx-npm</code> ระหว่าง publish workflow
 
 
npm provenance
 
artefact ที่เผยแพร่ถูกลงนามโดยใช้ npm package provenance
 
คุณสามารถตรวจสอบหลังการติดตั้งด้วย:
 
<code class="language-bash">npm view @sebastienrousseau/skeletonic-stylus@3.0.0 --json | \  jq '.dist."npm-signature"' </code></pre> 
การรับรองที่ลงนามเชื่อมโยง tarball กลับไปยัง GitHub Actions run ที่สร้างมันขึ้นมา
 
 
CVEs ที่ทราบและแพตช์
 
  
 CVE ระดับความรุนแรง สถานะ 
   
 CVE-2023-44270 (postcss line return parsing) ปานกลาง แก้ไขแล้ว ใน v2.0.0 ผ่าน <code>pnpm.overrides</code> ที่อัปเกรด <code>postcss</code> เป็น ≥ 8.4.31 
  
 
ฐานข้อมูลคำแนะนำ Snyk และ GitHub Security Advisories ถูกติดตามอย่างต่อเนื่อง; แพตช์ความปลอดภัยจะออกเป็น รีลีสระดับ patch
 
 
รายงานช่องโหว่
 
กรุณา อย่า เปิด GitHub issue สาธารณะสำหรับรายงานความปลอดภัย ใช้ช่องทางส่วนตัวแทน:
 
 
github.com/sebastienrousseau/skeletonic-stylus/security/advisories/new
 
 
รายงานจะได้รับการตอบรับภายใน 72 ชั่วโมง และแพตช์จะถูกส่งภายใน 14 วัน สำหรับปัญหาระดับปานกลาง และ 48 ชั่วโมง สำหรับ ปัญหาระดับวิกฤต
