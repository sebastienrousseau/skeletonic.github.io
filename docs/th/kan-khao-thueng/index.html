การเข้าถึง — WCAG 2.2 ใน v2.0.0

Translation note (2026-04-30). v2.0.0 adds RTL support and a refreshed 2026 framework comparison. The English source is the canonical reference while these translations catch up. See https://skeletonic.io/about/ · https://skeletonic.io/components/ · https://skeletonic.io/benchmarks/.

Skeletonic Stylus v2.0.0 มาพร้อมการรองรับ WCAG 2.2 เป็นพฤติกรรม เริ่มต้น ไม่ใช่ธีมเสริม หน้านี้อธิบายสิ่งที่รวมอยู่แล้วและ mixins ที่สามารถเลือกเปิดใช้เพื่อการควบคุมที่ละเอียดขึ้น

สิ่งที่คุณได้ฟรี

WCAG 2.2 SC สิ่งที่ v2.0.0 ทำ วิธีตรวจสอบ
1.4.3 คอนทราสต์ (ขั้นต่ำ) — AA <code>--cl-primary</code> และ <code>--cl-secondary</code> ถูกทำให้เข้มขึ้นเป็น ≥ 4.5:1 กับสีขาว DevTools → ตรวจสอบคอนทราสต์
1.4.11 คอนทราสต์ที่ไม่ใช่ข้อความ — AA ขอบฟอร์ม ปุ่ม ป้ายกำกับ ทั้งหมด ≥ 3:1 เช่นเดียวกัน
2.4.7 โฟกัสที่มองเห็นได้ — AA ทุกอิลิเมนต์ที่โฟกัสได้มีวงแหวน <code>:focus-visible</code> (เหลืองบนพื้นมืด น้ำเงินบนพื้นสว่าง) กด <code>Tab</code> ผ่านหน้าใดก็ได้
2.4.11 โฟกัสไม่ถูกบัง — AA (ใหม่ใน 2.2) ส่วนหัวแบบ sticky มีความสูงลดลง + scroll-margin ของโฟกัส กด <code>Tab</code> ผ่านส่วนหัว sticky
2.5.8 ขนาดเป้าหมาย — AA (ใหม่ใน 2.2) ปุ่ม / ลิงก์: ≥ 24×24 CSS px พื้นที่สัมผัส DevTools box model
1.4.12 ระยะห่างข้อความ — AA ทุกอิลิเมนต์รองรับการแก้ไข line-height / letter-spacing ของผู้ใช้ แก้ไขใน DevTools
2.3.3 แอนิเมชันจากการโต้ตอบ — AAA ทุกคลาสแอนิเมชันครอบด้วย <code>@media (prefers-reduced-motion: no-preference)</code> ลดการเคลื่อนไหวในระดับ OS
1.4.10 การไหลใหม่ — AA เลย์เอาต์ทำงานที่ 320 px โดยไม่มีสครอลแนวนอน DevTools viewport แคบ
โหมดมืด <code>prefers-color-scheme: dark</code> สลับโทเค็นอัตโนมัติ สลับโหมดมืดในระดับ OS

Stylus mixins ที่สามารถเลือกเปิดใช้

หากคุณคอมไพล์จากซอร์ส mixins ต่อไปนี้มีอยู่ใน <code>src/stylus/utilities/mixins.styl</code>:

Mixin การใช้งาน
<code>focus-ring()</code> วงแหวนโฟกัสคอนทราสต์สูงที่รองรับ <code>:focus-visible</code>
<code>visually-hidden()</code> ข้อความสำหรับ screen reader เท่านั้นที่ยังคงโฟกัสได้
<code>skip-link()</code> แอนเคอร์ที่มองเห็นได้เมื่อโฟกัส
<code>reduced-motion()</code> ครอบบล็อกใดก็ได้ใน <code>prefers-reduced-motion: no-preference</code>
<code>forced-colors()</code> การปรับแต่งสำหรับ Windows High Contrast Mode
<code>target-size(24px)</code> เพิ่ม padding ให้อิลิเมนต์คลิกได้ถึงขนาดเป้าหมายขั้นต่ำ

ตัวอย่าง:

<code class="language-stylus">// ใช้วงแหวนโฟกัสที่ชัดเจนบนปุ่มที่กำหนดเอง .my-button focus-ring() target-size(28px) </code></pre> 
 
ตัวช่วยลิงก์ข้าม
 
วางสิ่งนี้ เป็นอย่างแรกภายใน <code><body></code>:
 
<code class="language-html"><a href="#main-content" class="skip-link">ข้ามไปยังเนื้อหาหลัก</a> </code></pre> 
คลาสนี้ ไม่ได้ อยู่ในสไตล์ชีตหลัก (เพื่อไม่ให้เพิ่มน้ำหนักหน้า); เป็นสนิปเป็ต 4 บรรทัดที่คุณเขียนเองหรือใช้ mixin <code>skip-link()</code> ที่รวมมาให้ เว็บไซต์นี้ใช้อยู่ — โฟกัสที่หน้าแล้วกด Tab เพื่อดูมัน ปรากฏที่มุมบนซ้าย

<code class="language-bash">node scripts/a11y-test.mjs https://example.com </code></pre>
