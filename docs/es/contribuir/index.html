Contribuir

Skeletonic Stylus es un proyecto de codigo abierto; las contribuciones de todos los tamanos son bienvenidas — desde correcciones de erratas hasta nuevos componentes.

Inicio rapido

<code class="language-bash"># 1. Fork y clone git clone git@github.com:YOUR-USER/skeletonic-stylus.git cd skeletonic-stylus # 2. Instalar (pnpm via corepack) corepack enable pnpm install # 3. Compilar pnpm run build # pipeline completo (stylus → prettier → stylelint → autoprefixer → csso)  # 4. Lint y test pnpm run lint node scripts/a11y-test.mjs </code></pre> 
 
Convenciones
 
     
  • Nombres de ramas: <code>feat/descripcion-corta</code>, <code>fix/descripcion-corta</code>, <code>docs/descripcion-corta</code>.
    •  
  • Commits: Conventional Commits. Todos los commits estan firmados.
    •  
  • Stylus: indentacion de 4 espacios, sin punto y coma, preferir <code>$variables</code> sobre numeros magicos, cada clase publica vive en una capa de cascada.
    •  
  • Accesibilidad: cualquier componente nuevo debe cumplir de forma demostrable con WCAG 2.2 AA; ejecuta <code>node scripts/a11y-test.mjs</code> contra la pagina de muestra antes de abrir un PR.
    •  
  • Presupuesto de tamano: la hoja de estilos principal debe mantenerse por debajo de 8 KB gzipped. Si tu cambio lo supera, justificalo en el PR.
    •  
 
 
Pull requests
 
     
  1. Abre un issue primero para cualquier cosa no trivial — ahorra retrabajo.
    2.  
  2. Manten los PRs enfocados: un cambio logico por PR.
    3.  
  3. Actualiza el <code>CHANGELOG.md</code> bajo "Unreleased".
    4.  
  4. Asegurate de que CI este en verde antes de solicitar revision.
    5.  
  5. Squash-merge es lo predeterminado; los mensajes de commit se limpian al fusionar.
    6.  
 
 
Codigo de conducta
 
Al participar, aceptas cumplir con el Contributor Covenant 2.1. Se amable, ten paciencia, asume buenas intenciones.
