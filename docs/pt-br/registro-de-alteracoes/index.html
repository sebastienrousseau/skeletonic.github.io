v2.0.0 — 2026-04 (atual)

A revisao de "prontidao para release": a11y, cadeia de suprimentos, higiene do repositorio.

Acessibilidade (WCAG 2.2)

  • <code>$primary</code> escurecido para <code>hsl(210, 100%, 42%)</code> para contraste AA contra texto branco em botoes / badges / links.
  • <code>$secondary</code> escurecido para <code>hsl(195, 100%, 33%)</code>.
  • Adicionados aneis focus-visible em cada elemento interativo.
  • Adicionado wrapper <code>@media (prefers-reduced-motion)</code> no modulo de animacoes.
  • Adicionada troca de tokens <code>prefers-color-scheme: dark</code>.
  • Adicionado mixin target-size(24px) para atender WCAG 2.2 SC 2.5.8.
  • Adicionados helpers focus-not-obscured de scroll-margin para headers fixos.

Build & cadeia de suprimentos

  • Cascade layers — cada bloco agora vive em <code>@layer skeletonic.{reset,tokens,layout,elements,components,utilities}</code>.
  • CycloneDX SBOM gerado como parte do tarball npm.
  • Budgets <code>size-limit</code> aplicados no CI: limite de 8 KB gzipped na folha de estilos principal.
  • CVE-2023-44270 (retorno de linha do postcss) corrigido via <code>pnpm.overrides</code>.
  • Procedencia + assinatura no workflow de publicacao npm (<code>--provenance --access public</code>).
  • Removido plugin arquivado <code>stylelint-a11y</code> da configuracao de lint.

Higiene do repositorio & pacote para consumidores

  • Diretorio legado <code>package/</code> removido; <code>dist/</code> e agora a unica fonte de verdade para consumidores.
  • README reescrito para refletir os caminhos de instalacao da v2.0.0.
  • <code>dist/</code> e commitado; <code>debug/</code> e gerado e incluido no gitignore.
  • Novo <code>.github/workflows/npm-publish.yml</code> acionado por tags.

Correcoes de bugs (P0)

  • Regressao de seletor pai <code>row $:after</code> — substituido <code>$</code> avulso por <code>&</code> em <code>src/stylus/components/_grid.styl</code>.
  • <code>.alternate</code> aplicava erroneamente <code>animation-direction: reverse</code> em vez de <code>alternate</code>.
  • Namespacing <code>.alert-*</code> — <code>.alert.success</code> → <code>.alert.alert-success</code> para evitar colisoes com classes de estado.
