v2.0.0 — 2026-04 (lọwọlọwọ)

Ipari "imurasilẹ-itusilẹ": a11y, ẹwọn ipese, itọju ibi-ipamọ.

Irayẹ-si (WCAG 2.2)

  • <code>$primary</code> ti a ṣe dudu si <code>hsl(210, 100%, 42%)</code> fun iyatọ AA si ọrọ funfun ninu awọn bọtini / awọn aami / awọn ọna asopọ.
  • <code>$secondary</code> ti a ṣe dudu si <code>hsl(195, 100%, 33%)</code>.
  • A fi awọn oruka focus-visible kun lori gbogbo ẹya ibaraṣepọ.
  • A fi <code>@media (prefers-reduced-motion)</code> afikun kun si modulu ere idasọnu.
  • A fi <code>prefers-color-scheme: dark</code> iyipada ami kun.
  • A fi adalu target-size(24px) kun lati ni itẹlọrun WCAG 2.2 SC 2.5.8.
  • A fi awọn oluranlọwọ scroll-margin focus-not-obscured kun fun awọn akọle didimu.

Ikọ & ẹwọn ipese

  • Awọn ipele cascade — gbogbo bulọọki ngbe ni bayi ninu <code>@layer skeletonic.{reset,tokens,layout,elements,components,utilities}</code>.
  • CycloneDX SBOM ti a ṣẹda gẹgẹ bi apakan ti tarball npm.
  • Awọn isuna <code>size-limit</code> ti a fi ipa mu ninu CI: opin 8 KB gzipped lori iwe-aṣa ipilẹ.
  • CVE-2023-44270 (postcss line return) ti a ṣe atunṣe nipasẹ <code>pnpm.overrides</code>.
  • Ẹri + fọwọsi lori opo iṣẹ tẹ npm (<code>--provenance --access public</code>).
  • A yọ plugin <code>stylelint-a11y</code> ti a fi pamọ kuro ninu iṣeto lint.

Itọju ibi-ipamọ & package olumulo

  • A yọ itọsọna <code>package/</code> atijọ kuro; <code>dist/</code> ni orisun otitọ kan bayi fun awọn olumulo.
  • A tun README kọ lati ṣe afihan awọn ọna fifi sori ẹrọ v2.0.0.
  • A fi <code>dist/</code> sinu adehun; a ṣẹda <code>debug/</code> ti a si fi sinu gitignore.
  • <code>.github/workflows/npm-publish.yml</code> tuntun ni ami-akọle wakọ.

Awọn atunṣe aṣiṣe (P0)

  • Ipadabọ oluyẹwo obi <code>row $:after</code> — a fi <code>&</code> rọpo <code>$</code> aṣiṣe ninu <code>src/stylus/components/_grid.styl</code>.
  • <code>.alternate</code> fi <code>animation-direction: reverse</code> ranṣẹ lairotẹlẹ dipo <code>alternate</code>.
  • Orukọ <code>.alert-*</code> — <code>.alert.success</code> → <code>.alert.alert-success</code> lati yẹra fun ikọlu pẹlu awọn kilasi ipo.
