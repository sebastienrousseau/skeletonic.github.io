Bẹrẹ pẹlu Skeletonic Stylus

Translation note (2026-04-30). v2.0.0 adds RTL support and a refreshed 2026 framework comparison. The English source is the canonical reference while these translations catch up. See https://skeletonic.io/about/ · https://skeletonic.io/components/ · https://skeletonic.io/benchmarks/.

Ifihan

Ṣe o tuntun si Skeletonic Stylus? Ninu v2.0.0 o rọrun ju ti tẹlẹ lọ lati yan awọn ẹya ti o nilo nikan. O ṣeun si iwọn kekere rẹ (7.7 KB gzipped fun iwe-aṣa akọkọ), o darapọ mọ ohun elo wẹẹbu eyikeyi ni kiakia — ko si ilana JavaScript ti a beere, ko si igbesẹ ikọ ti a nilo ti o ba lo CDN.

Ṣe o setan lati fi sori ẹrọ? Gbogbo ọna ni a ṣe alaye ni isalẹ — yan eyi ti o ba ọ mu.

1. Gba silẹ ki o si fi sori ẹrọ

O le fi Skeletonic Stylus sori ẹrọ nipasẹ pnpm, npm tabi yarn, tabi gba a taara lati CDN. O tun le gbalejo awọn faili pinpin ni agbegbe ti o ba fẹ.

Lati oluṣakoso package (ti a ṣe iṣeduro)

<code class="language-bash"># pnpm pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0 # npm npm install @sebastienrousseau/skeletonic-stylus@3.0.0 # yarn yarn add @sebastienrousseau/skeletonic-stylus@3.0.0 </code></pre> 
Lati CDN
 
Ti o ba nilo CSS ti a ṣajọ nikan, fi ọkan ninu iwọnyi sinu <code><head></code> rẹ:
 
<code class="language-html"><!-- jsDelivr --> <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@sebastienrousseau/skeletonic-stylus@3.0.0/css/core/skeletonic.min.css" crossorigin="anonymous"> <!-- unpkg --> <link rel="stylesheet" href="https://unpkg.com/@sebastienrousseau/skeletonic-stylus@3.0.0/css/core/skeletonic.min.css" crossorigin="anonymous"> </code></pre> 
Fun iduroṣinṣin ti o pọ julọ, daakọ SRI hash lati awọn akọsilẹ itusilẹ v2.0.0 ki o fi ẹya <code>integrity="sha384-…"</code> kun.

Gba itusilẹ GitHub
 
Ṣe o fẹ tarball ti a ṣe ẹya? Gba itusilẹ tuntun lati github.com/sebastienrousseau/skeletonic-stylus/releases ki o fi awọn akoonu <code>dist/</code> taara sinu iṣẹ-akanṣe rẹ.
 
Ṣe daakọ ibi-ipamọ GitHub
 
Ṣe daakọ ibi-ipamọ akọkọ lati gba gbogbo awọn faili orisun pẹlu awọn iwe afọwọkọ ikọ:
 
<code class="language-bash">git clone https://github.com/sebastienrousseau/skeletonic-stylus.git cd skeletonic-stylus pnpm install pnpm run build </code></pre> 
 
Imọran: fọwọsi awọn adehun rẹ — iṣẹ-akanṣe naa fi ipa mu awọn adehun ti a fọwọsi ninu CI. Lo <code>git commit -S -m "..."</code> (tabi ṣeto <code>commit.gpgsign = true</code> ninu git config gbogbogbo rẹ).
 
 
2. Lo CSS ti a ṣajọ
 
Ile-ikawe naa fi ọpọlọpọ awọn akopọ ti a ti kọ tẹlẹ ranṣẹ labẹ <code>dist/css/</code> lẹhin ifisori ẹrọ:
 
  
 Faili Idi Iwọn (min/gz) 
   
 <code>core/skeletonic.min.css</code> Atunṣeto + awọn ami + eto + awọn ẹya + awọn paati + awọn iwulo 38.8 KB / 7.7 KB 
 
 <code>animations/skeletonic-animations.min.css</code> Modulu ere idasọnu yan ≈213 KB / ≈6.7 KB 
 
 <code>palettes/material/skeletonic-material.min.css</code> Palẹti awọ Material ≈17.4 KB

Modulu kọọkan jẹ ominira — yan apapọ ti o kere julọ ti o nilo.
 
3. Lo o lati Stylus
 
Ti o ba ni opo Stylus tẹlẹ, o le mu awọn modulu orisun wọle ki o jẹ ki bundler rẹ yọ awọn apakan ti a ko lo kuro:
 
<code class="language-stylus">// styles/main.styl @import '~@sebastienrousseau/skeletonic-stylus/src/stylus/skeletonic' </code></pre> 
Tabi mu awọn apakan ti o nilo nikan wọle:
 
<code class="language-stylus">@import '~@sebastienrousseau/skeletonic-stylus/src/stylus/utilities/variables' @import '~@sebastienrousseau/skeletonic-stylus/src/stylus/utilities/mixins' @import '~@sebastienrousseau/skeletonic-stylus/src/stylus/elements/buttons' @import '~@sebastienrousseau/skeletonic-stylus/src/stylus/components/card' </code></pre> 
4. Ṣe atunṣe awọ ami iyasọtọ
 
Skeletonic ṣafihan awọn ami apẹrẹ rẹ bi awọn ohun-ini aṣa CSS nitorinaa o le ṣe aṣa rẹ laisi atunṣe Stylus:
 
<code class="language-css">:root { --cl-primary: hsl(210, 100%, 42%); --cl-secondary: hsl(195, 100%, 33%); --cl-tertiary: #757c8a; } </code></pre> 
Iyẹn ni — gbogbo paati ti o lo awọ akọkọ yoo tẹle.
 
5. Ṣe idaniloju ifisori ẹrọ
 
Ayẹwo "ṣe o ṣiṣẹ?" ti o kere julọ:
 
<code class="language-html"><!doctype html> <html lang="yo"> <head> <meta charset="utf-8"> <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@sebastienrousseau/skeletonic-stylus@3.0.0/css/core/skeletonic.min.css"> </head> <body class="container padding-3"> <h1>O n ṣiṣẹ.</h1> <a href="#" class="button primary">Pẹlẹ o, agbaye</a> </body> </html> </code></pre> 
Ti akọle ba ti ni iwọn ni irọrun ti bọtini si ni apẹrẹ egbogi buluu, o ti pari.
 
6. Ohun ti o wa ninu
 
Ninu package naa iwọ yoo ri gbogbo faili orisun, awọn akopọ CSS ti a ṣajọ ati ti a dinku, awọn maapu orisun, ati igi Stylus kan ti a ṣeto nipasẹ ẹka:
 
<code class="language-text">@sebastienrousseau/skeletonic-stylus@3.0.0 ├── CHANGELOG.md ├── LICENSE-APACHE ├── LICENSE-MIT ├── README.md ├── package.json ├── dist/ │ └── css/ │ ├── core/ │ │ ├── skeletonic.css │ │ ├── skeletonic.css.map │ │ └── skeletonic.min.css │ ├── animations/ │ │ ├── skeletonic-animations.css │ │ └── skeletonic-animations.min.css │ └── palettes/ │ ├── material/skeletonic-material.min.css │ ├── tachyons/skeletonic-tachyons.min.css │ └── websafe/skeletonic-websafe.min.css └── src/ └── stylus/ ├── animations/ bounce, fade, pulse, shake, vanish, zoom… ├── base/ atunṣeto, awọn oluranlọwọ ├── components/ kaadi, akọle, navbar, itaniji ├── configurations/ awọn awọ, awọn oniyipada ├── elements/ bọtini, fọọmu, tabili, ọna asopọ, atokọ, koodu… ├── fonts/ awọn ikede font-face ├── layout/ apoti, grid, media-queries ├── palettes/ material, tachyons, websafe ├── utilities/ awọn adalu └── skeletonic.styl ← agbewọle kan ti o fa ohun gbogbo </code></pre> 
Modulu kọọkan jẹ ominira — fa awọn akopọ ti o nilo nikan lati jẹ ki aṣẹ CSS rẹ kere bi o ti ṣee.
 
Awọn ibeere ti a ma n beere nigbagbogbo
 
Bawo ni MO ṣe le fi Skeletonic Stylus sori ẹrọ? Ṣiṣẹ <code>pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0</code>. Tabi gba CSS ti a ṣajọ taara lati CDN — ko si igbesẹ ikọ ti a beere.
 
Ṣe o nilo JavaScript? Rara. Iwe-aṣa akọkọ jẹ CSS mimọ, pẹlu iye owo iṣiṣẹ odo. Awọn paati ṣiṣẹ laisi ila JS kan.
 
Ṣe o setan fun WCAG 2.2? Bẹẹni. v2.0.0 fi iyatọ ti o ni ibamu AA, awọn oruka focus-visible, awọn oluranlọwọ skip-link, atilẹyin idinku-iṣipopada ati ipo dudu nipasẹ aiyipada ranṣẹ.
 
Kini iwọn gzipped? 38.8 KB minified, 7.7 KB gzipped, 6.7 KB brotli fun iwe-aṣa akọkọ ni kikun. Opin 8 KB ni a fi ipa mu ninu CI.
 
Kini iwe-aṣẹ ti o lo? Ti a fun ni iwe-aṣẹ meji labẹ MIT ati Apache 2.0 — yan eyikeyi ti iṣẹ-akanṣe rẹ nilo. Ọfẹ fun lilo iṣowo ati ti ara ẹni.
