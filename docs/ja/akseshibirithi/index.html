アクセシビリティ — v2.0.0 における WCAG 2.2

Translation note (2026-04-30). v2.0.0 adds RTL support and a refreshed 2026 framework comparison. The English source is the canonical reference while these translations catch up. See https://skeletonic.io/about/ · https://skeletonic.io/components/ · https://skeletonic.io/benchmarks/.

Skeletonic Stylus v2.0.0 は、WCAG 2.2 準拠をオプションテーマとしてではなく、デフォルトの動作として提供します。 このページでは、組み込み済みの機能と、より細かい制御のためにオプトインできるミックスインについて説明します。

標準で得られるもの

WCAG 2.2 SC v2.0.0 の対応内容 確認方法
1.4.3 コントラスト (最低限) — AA <code>--cl-primary</code> と <code>--cl-secondary</code> を白いテキストに対して 4.5:1 以上に調整 DevTools → コントラストチェッカー
1.4.11 非テキストコントラスト — AA フォームボーダー、ボタン、バッジすべて 3:1 以上 同上
2.4.7 フォーカスの可視性 — AA すべてのフォーカス可能な要素に <code>:focus-visible</code> リング（暗い背景では黄色、明るい背景では青） <code>Tab</code> キーで任意のページを移動
2.4.11 フォーカスの非遮蔽 — AA (2.2で新規) 固定ヘッダーの高さ縮小 + フォーカス scroll-margin 固定ヘッダーを越えて <code>Tab</code>
2.5.8 ターゲットサイズ — AA (2.2で新規) ボタン/リンク: 最小 24×24 CSS px ヒットエリア DevTools ボックスモデル
1.4.12 テキスト間隔 — AA すべての要素がユーザーの line-height / letter-spacing オーバーライドを尊重 DevTools でオーバーライド
2.3.3 インタラクションによるアニメーション — AAA すべてのアニメーションクラスが <code>@media (prefers-reduced-motion: no-preference)</code> でラップ OS レベルのモーション軽減
1.4.10 リフロー — AA 320 px でも水平スクロールなしでレイアウトが機能 DevTools 狭いビューポート
ダークモード <code>prefers-color-scheme: dark</code> でトークンを自動切替 OS のダークモード切替

オプトインできる Stylus ミックスイン

ソースからコンパイルする場合、以下のミックスインが <code>src/stylus/utilities/mixins.styl</code> で利用可能です：

ミックスイン 用途
<code>focus-ring()</code> <code>:focus-visible</code> を尊重する高コントラストフォーカスリング
<code>visually-hidden()</code> フォーカス可能のまま残るスクリーンリーダー専用テキスト
<code>skip-link()</code> フォーカス時に表示されるアンカー
<code>reduced-motion()</code> 任意のブロックを <code>prefers-reduced-motion: no-preference</code> でラップ
<code>forced-colors()</code> Windows ハイコントラストモード用の調整
<code>target-size(24px)</code> クリック可能な要素を最小タップターゲットにパディング

使用例：

<code class="language-stylus">// カスタムボタンに強いフォーカスリングを適用 .my-button focus-ring() target-size(28px) </code></pre> 
 
スキップリンクヘルパー
 
以下を <code><body></code> の最初 に配置してください：
 
<code class="language-html"><a href="#main-content" class="skip-link">メインコンテンツへスキップ</a> </code></pre> 
このクラスはコアスタイルシートには含まれていません（ページ容量に影響しないようにするため）。4行のスニペットを自分で構成するか、含まれている <code>skip-link()</code> ミックスインを使用してください。このサイトでも使用しています — ページにフォーカスして Tab を押すと、左上に表示されます。
 
 
自分のページの検証
 
ライブラリには <code>scripts/</code> 以下に <code>a11y-test.mjs</code> スクリプトが含まれており、指定した URL に対して axe-core を実行します。
 
<code class="language-bash">node scripts/a11y-test.mjs https://example.com </code></pre> 
CI はこのスクリプトを毎プッシュ時に <code>dist/index.html</code> ショーケースページに対して実行します。
