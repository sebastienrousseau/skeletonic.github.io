v2.0.0 — 2026-04 (поточний)

Прохід «готовність до релізу»: a11y, ланцюг постачання, гігієна репозиторію.

Доступність (WCAG 2.2)

  • <code>$primary</code> затемнено до <code>hsl(210, 100%, 42%)</code> для контрасту AA відносно білого тексту в кнопках / значках / посиланнях.
  • <code>$secondary</code> затемнено до <code>hsl(195, 100%, 33%)</code>.
  • Додано кільця focus-visible на кожному інтерактивному елементі.
  • Додано обгортку <code>@media (prefers-reduced-motion)</code> навколо модуля анімацій.
  • Додано <code>prefers-color-scheme: dark</code> — автоматичну заміну токенів.
  • Додано міксин target-size(24px) для відповідності WCAG 2.2 SC 2.5.8.
  • Додано хелпери focus-not-obscured зі scroll-margin для липких заголовків.

Збірка та ланцюг постачання

  • Каскадні шари — кожен блок тепер знаходиться в <code>@layer skeletonic.{reset,tokens,layout,elements,components,utilities}</code>.
  • CycloneDX SBOM генерується як частина npm-архіву.
  • Бюджети <code>size-limit</code> контролюються в CI: обмеження 8 КБ gzip для основної таблиці стилів.
  • CVE-2023-44270 (postcss — переноси рядків) виправлено через <code>pnpm.overrides</code>.
  • Провенанс + підпис у робочому процесі npm publish (<code>--provenance --access public</code>).
  • Видалено архівний плагін <code>stylelint-a11y</code> з конфігурації лінтинга.

Гігієна репозиторію та споживчий пакет

  • Застарілий каталог <code>package/</code> видалено; <code>dist/</code> тепер єдине джерело істини для споживачів.
  • README переписано відповідно до шляхів встановлення v2.0.0.
  • <code>dist/</code> фіксується; <code>debug/</code> генерується та додано до gitignore.
  • Новий <code>.github/workflows/npm-publish.yml</code> працює за тегами.

Виправлення помилок (P0)

  • Регресія батьківського селектора <code>row $:after</code> — помилковий <code>$</code> замінено на <code>&</code> у <code>src/stylus/components/_grid.styl</code>.
  • <code>.alternate</code> помилково застосовувався <code>animation-direction: reverse</code> замість <code>alternate</code>.
  • Простір імен <code>.alert-*</code> — <code>.alert.success</code> → <code>.alert.alert-success</code> для уникнення конфліктів із класами стану.
