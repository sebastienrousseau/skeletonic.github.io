v2.0.0 — 2026-04 (attuale)

Il passaggio di "preparazione al rilascio": a11y, supply chain, igiene del repository.

Accessibilita (WCAG 2.2)

  • <code>$primary</code> scurito a <code>hsl(210, 100%, 42%)</code> per contrasto AA contro il testo bianco in pulsanti / badge / link.
  • <code>$secondary</code> scurito a <code>hsl(195, 100%, 33%)</code>.
  • Aggiunti anelli focus-visible su ogni elemento interattivo.
  • Aggiunto wrapper <code>@media (prefers-reduced-motion)</code> attorno al modulo animazioni.
  • Aggiunto scambio token <code>prefers-color-scheme: dark</code>.
  • Aggiunto mixin target-size(24px) per soddisfare WCAG 2.2 SC 2.5.8.
  • Aggiunti helper focus-not-obscured con scroll-margin per header fissi.

Build & supply chain

  • Cascade layers — ogni blocco ora risiede in <code>@layer skeletonic.{reset,tokens,layout,elements,components,utilities}</code>.
  • CycloneDX SBOM generato come parte dell'archivio npm.
  • Budget <code>size-limit</code> imposti nella CI: limite di 8 KB gzipped sul foglio di stile principale.
  • CVE-2023-44270 (parsing line return di postcss) corretta tramite <code>pnpm.overrides</code>.
  • Provenienza + firma nel workflow di pubblicazione npm (<code>--provenance --access public</code>).
  • Rimosso il plugin archiviato <code>stylelint-a11y</code> dalla configurazione lint.

Igiene del repository & pacchetto per i consumatori

  • Directory legacy <code>package/</code> rimossa; <code>dist/</code> e ora l'unica fonte di verita per i consumatori.
  • README riscritto per riflettere i percorsi di installazione v2.0.0.
  • <code>dist/</code> e committato; <code>debug/</code> e generato e incluso nel gitignore.
  • Nuovo <code>.github/workflows/npm-publish.yml</code> guidato da tag.

Correzioni bug (P0)

  • Regressione del selettore padre <code>row $:after</code> — sostituito <code>$</code> errato con <code>&</code> in <code>src/stylus/components/_grid.styl</code>.
  • <code>.alternate</code> applicava erroneamente <code>animation-direction: reverse</code> invece di <code>alternate</code>.
  • Namespace <code>.alert-*</code> — <code>.alert.success</code> → <code>.alert.alert-success</code> per evitare collisioni con classi di stato.
