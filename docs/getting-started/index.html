Getting started with Skeletonic Stylus

Intro

New to Skeletonic Stylus? In v2.0.0 the core stylesheet is 7.7 KB gzip / 6.7 KB brotli for the full RTL-ready, WCAG 2.2 AA bundle — measured against the canonical CDN file, not approximated. It integrates into any web app from a single <code>&lt;link&gt;</code> — no JavaScript framework required, no build step needed if you load it from a CDN.

Ready to install? Every path covered below — pick one.

0. Zero-to-running in 30 seconds (<code>npx</code>)

The fastest path. No package install, no build step:

<code class="language-bash">npx @sebastienrousseau/skeletonic-stylus init </code></pre> 
Scaffolds <code>styles/index.styl</code> + a working <code>index.html</code> in the current directory, both pointing at the CDN bundle. Open <code>index.html</code> and you're running.
 
<code class="language-bash"># Add a single component's source to your project tree: npx @sebastienrousseau/skeletonic-stylus add card # List everything available: npx @sebastienrousseau/skeletonic-stylus list </code></pre> 
1. Download and install
 
You can install Skeletonic Stylus via pnpm, npm or yarn, or load it straight from a CDN. You can also self-host the distribution files locally if you prefer.
 
From a package manager (recommended)
 
<code class="language-bash"># pnpm pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0 # npm npm install @sebastienrousseau/skeletonic-stylus@3.0.0 # yarn yarn add @sebastienrousseau/skeletonic-stylus@3.0.0 </code></pre> 
From a CDN
 
If you only need the compiled CSS, drop one of these into your <code>&lt;head&gt;</code>:
 
<code class="language-html"><!-- jsDelivr --> <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@sebastienrousseau/skeletonic-stylus@3.0.0/css/core/skeletonic.min.css" crossorigin="anonymous"> <!-- unpkg --> <link rel="stylesheet" href="https://unpkg.com/@sebastienrousseau/skeletonic-stylus@3.0.0/css/core/skeletonic.min.css" crossorigin="anonymous"> </code></pre> 
For maximum integrity, copy the SRI hash from the v2.0.0 release notes and add an <code>integrity="sha384-…"</code> attribute.

Download the GitHub release
 
Prefer a versioned tarball? Grab the latest release from github.com/sebastienrousseau/skeletonic-stylus/releases and drop the contents of <code>dist/</code> straight into your project.
 
Clone the GitHub repository
 
Clone the main repository to get all source files including the build scripts:
 
<code class="language-bash">git clone https://github.com/sebastienrousseau/skeletonic-stylus.git cd skeletonic-stylus pnpm install pnpm run build </code></pre> 
 
Tip: sign your commits — the project enforces signed commits in CI. Use <code>git commit -S -m "..."</code> (or set <code>commit.gpgsign = true</code> in your global git config).
 
 
2. Use the compiled CSS
 
The library ships several pre-built bundles under <code>dist/css/</code> once installed:
 
  
 File Purpose Min raw / gzip / brotli 
   
 <code>core/skeletonic.min.css</code> Reset + tokens + layout + elements + components + utilities, RTL-ready 38.8 KB / 7.7 KB / 6.7 KB 
 
 <code>animations/skeletonic-animations.min.css</code> 56 keyframes, gated behind <code>prefers-reduced-motion</code> 217.7 KB / 6.7 KB / — 
 
 <code>palettes/material/skeletonic-material.min.css</code> Material 19×14 hue/shade utilities ≈17.7 KB 
 
 <code>palettes/tachyons/skeletonic-tachyons.min.css</code> Tachyons utility palette 7.3 KB 
 
 <code>palettes/websafe/skeletonic-websafe.min.css</code> ~140 CSS named-color utilities ≈3.5 KB 
  
 
Each module is independent — pick the smallest combination you need.
 
3. Use it from Stylus
 
If you have a Stylus pipeline already, you can import the source modules and let your bundler tree-shake unused parts:
 
<code class="language-stylus">// styles/main.styl @import '~@sebastienrousseau/skeletonic-stylus/src/stylus/skeletonic' </code></pre> 
Or import only the bits you need:
 
<code class="language-stylus">@import '~@sebastienrousseau/skeletonic-stylus/src/stylus/utilities/variables' @import '~@sebastienrousseau/skeletonic-stylus/src/stylus/utilities/mixins' @import '~@sebastienrousseau/skeletonic-stylus/src/stylus/elements/buttons' @import '~@sebastienrousseau/skeletonic-stylus/src/stylus/components/card' </code></pre> 
4. Override the brand colour
 
Skeletonic exposes its design tokens as CSS custom properties so you can theme it without recompiling Stylus:
 
<code class="language-css">:root { --cl-primary: oklch(0.55 0.2 250); --cl-secondary: oklch(0.45 0.15 200); --cl-tertiary: #757c8a; } </code></pre> 
That's it — every component that uses the primary colour will follow.
 
5. Verify the install
 
A minimal "did it work?" check:
 
<code class="language-html"><!doctype html> <html lang="en"> <head> <meta charset="utf-8"> <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@sebastienrousseau/skeletonic-stylus@3.0.0/css/core/skeletonic.min.css"> </head> <body class="container padding-3"> <h1>It works.</h1> <a href="#" class="button primary">Hello, world</a> </body> </html> </code></pre> 
If the heading is sized fluidly and the button has a blue pill shape, you're done.

Frequently asked questions
 
How do I install Skeletonic Stylus? Run <code>pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0</code>. Or load the compiled CSS straight from a CDN — no build step required.
 
Does it require JavaScript? No. The core stylesheet is pure CSS, with zero runtime cost. Components work without a single line of JS.
 
Is it WCAG 2.2 ready? Yes. v2.0.0 ships AA-conformant contrast, focus-visible rings, skip-link helpers, reduced-motion support and dark mode by default.
 
What's the gzipped size? 38.8 KB minified, 7.7 KB gzip, 6.7 KB brotli for the full RTL-ready core stylesheet. Compressed budgets (10 KB gzip, 8 KB brotli) are enforced in CI on every commit. See the framework benchmark for side-by-side numbers against Bootstrap, Bulma, Pico, and Tailwind.
 
What licence does it use? Dual-licensed under MIT and Apache 2.0 — pick whichever your project needs. Free for commercial and personal use.
