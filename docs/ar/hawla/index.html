باختصار

Skeletonic Stylus هي مكتبة CSS مفتوحة المصدر مبنية بـ Stylus صُمّمت لتنسيق واجهات مستخدم يسهل الوصول إليها، سريعة ومعيارية.

وُلدت عام 2018 كتجربة شخصية في تقليل حجم CSS المُرسل دون التخلي عن الراحة التي توفرها مكتبة مكوّنات حقيقية. بعد ثماني سنوات، الهدف لم يتغير.

ما الذي تقدّمه لك

سريعة كالبرق

صمّم وخصّص واجهات متجاوبة في دقائق. متغيرات CSS أصلية، فئات معرّفة مسبقًا، شبكة من 12 عمودًا تغطي كل عنصر HTML دلالي.

خفيفة الوزن

بحجم ~7.5 كيلوبايت مضغوط. الصفحات تُحمّل أسرع. جميع لبنات البناء الأساسية متوفرة.

تصميم متجاوب

مصمّمة لسطح المكتب والهاتف. التخطيطات تتكيّف مع أي جهاز. محسّنة للمس، مع HTML دلالي في كل مكان.

إمكانية الوصول

WCAG 2.2 مدمج: حلقات focus-visible، تباين AA، مساعدات رابط التخطي، مكوّنات صديقة للوحة المفاتيح، دعم تقليل الحركة — بدون ورقة أنماط إضافية، وبدون نمطية <code>aria-*</code>.

مكتبة مكوّنات

مكوّنات CSS معيارية وخلطات Stylus. أزرار، نماذج، بطاقات، تنبيهات، شارات، لوحات ألوان وحركات — نظيفة، معيارية، جاهزة للإضافة.

مجانية ومفتوحة المصدر

صمّمها وبناها وصانها Sebastien Rousseau. مرخّصة بشكل مزدوج تحت MIT أو Apache 2.0. بدون رسوم، بدون تكاليف ترخيص، حتى للاستخدام التجاري.

كيف تُقارَن

ورقة أنماط واحدة مستضافة ذاتيًا تغطي الطباعة والأزرار والنماذج والبطاقات والجداول ولوحات الألوان والحركات وفئات الأدوات المساعدة. بدون JavaScript. بدون خطوة بناء مطلوبة. بدون تبعيات نظيرة على Bootstrap أو Tailwind أو Bulma.

المبادئ

  1. إمكانية الوصول هي الأساس، وليست السقف. توافق WCAG 2.2 مدمج في كل مكوّن، ولا يُضاف لاحقًا كـ "مظهر".
  2. البايتات مهمة. ورقة أنماط واحدة مُرسلة لا ينبغي أن تستنفد ميزانية وزن صفحتك. الحد الأقصى 8 كيلوبايت مضغوط يُفرض في CI.
  3. طبقات التسلسل تتغلب على حروب الخصوصية. تجاوز أي شيء بثقة — بدون <code>!important</code>، بدون حيل ترتيب DOM.
  4. Stylus لا يزال جيدًا. موجز، معبّر، ويتيح للمكتبة البقاء في ~3,000 سطر قابل للقراءة.
  5. البساطة ميزة. بدون تبعيات JS. بدون سحر وقت البناء. بدون إعادة تسمية مُعطّلة. فئات CSS تفعل بالضبط ما يقوله اسمها.
  6. قابلة للتخصيص في ثوانٍ. خصائص CSS مخصصة أصلية للألوان والمسافات والخط والحواف المستديرة.
  7. مُحصّنة ضد هجمات سلسلة التوريد. مصدر npm موقّع. تحديثات Dependabot مثبّتة. ثغرة CVE-2023-44270 مرقّعة عبر overrides.
