Spacing — Skeletonic Stylus

يتم توفير الوثائق التفصيلية لهذا القسم حاليًا باللغة الإنجليزية أدناه. نحن نعمل على ترجمة كاملة. <!-- i18n-summary -->

The padding and margin utility classes in Skeletonic share a single five-step golden-ratio scale. Each step is rooted at <code>--gr-fsb</code> (1.62 rem, the body font size) and scales up or down by factors of Φ. The result is layout that breathes consistently from inline buttons all the way to hero sections.

The five steps

Class Value Token Use it for
<code>xs</code> ~0.38 rem <code>var(--gr-small)rem</code> Pill icons, badge inset, very tight clusters
<code>sm</code> ~0.62 rem <code>var(--gr-large)rem</code> Inline form gaps, button-group separators
<code>md</code> 1.62 rem <code>var(--gr-fsb)rem</code> Default body / card padding
<code>lg</code> ~2.62 rem <code>calc(var(--gr-fsb) × Φ)</code> Section breathing room
<code>xl</code> ~4.24 rem <code>calc(var(--gr-fsb) × Φ²)</code> Hero / landmark separation

Values are emitted as <code>rem</code> units so they scale with the user's root font-size — perfect for accessibility and for matching the type scale exactly.

Available class forms

For every step (<code>xs</code> / <code>sm</code> / <code>md</code> / <code>lg</code> / <code>xl</code>) the library emits:

<code class="language-text">.padding-{size} .margin-{size} .padding-top-{size} .margin-top-{size} .padding-bottom-{size} .margin-bottom-{size} .padding-start-{size} .margin-start-{size} ← logical, RTL-aware .padding-end-{size} .margin-end-{size} ← logical, RTL-aware .margin-auto ← centring helper </code></pre> 
The logical (<code>-start</code> / <code>-end</code>) forms compile to <code>padding-inline-start</code> / <code>padding-inline-end</code> (or <code>margin-inline-*</code>) so they auto-flip in <code><html dir="rtl"></code>. Pair them with the t-shirt size to get <code>padding-start-md</code>, <code>margin-end-lg</code>, etc.
 
 
v1.x → v2.0 migration. The numeric scale (<code>.padding-0</code> through <code>.padding-11</code>, percentage-based) was replaced with this five-step rem-based scale. The new system is shorter, more predictable, and easier to reason about. See the changelog for the full migration list.
