隐私政策

概要

skeletonic.io 不设置追踪 cookies，也不运行任何第三方分析标签。 本站是一组静态 HTML、CSS 和一个 Service Worker 文件。你发出的任何请求均不会被记录，仅有标准的 GitHub Pages 访问日志。

收集哪些数据

  1. GitHub Pages 访问日志。 当你加载任何页面时，GitHub 会记录你的 IP 地址、请求 URL 和时间。适用 GitHub 的隐私政策——参见 docs.github.com/en/site-policy。
  2. 联系表单。 如果你在 <code>/zh-hans/lian-xi/</code> 提交表单，数据将通过 Formspree 转发至维护者的邮箱。适用 Formspree 的隐私政策。
  3. Service Worker。 <code>sw.js</code> 脚本将 HTML、CSS、JS 和图片响应缓存到你的本地浏览器中，使站点可离线访问。不会向任何地方发送数据。

不收集哪些数据

  • 无 Google Analytics、Plausible、Fathom 或任何其他分析标签。
  • 无任何类型的 cookies。本站不设置 cookies。
  • 除 Service Worker 缓存外，无 Local Storage 或 IndexedDB。
  • 无指纹识别、广告网络或第三方追踪器。

你的权利

如果你使用过联系表单并希望删除你的消息，请从你提交时使用的邮箱发送邮件给我，我将在 30 天内删除。
