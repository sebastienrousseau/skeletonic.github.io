CycloneDX SBOM

हर प्रकाशित tarball में <code>dist/sbom.json</code> पर CycloneDX SBOM शामिल है। ताज़ा इंस्टॉल किए पैकेज को इस प्रकार सत्यापित करें:

<code class="language-bash">pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0 jq '.metadata.component.version' \  node_modules/@sebastienrousseau/skeletonic-stylus/dist/sbom.json # → "2.0.0" </code></pre> 
SBOM प्रकाशन वर्कफ़्लो के दौरान <code>cyclonedx-npm</code> से जनरेट होता है।
 
 
npm provenance
 
प्रकाशित आर्टिफ़ैक्ट npm package provenance से हस्ताक्षरित है।
 
इंस्टॉलेशन के बाद इस प्रकार सत्यापित करें:
 
<code class="language-bash">npm view @sebastienrousseau/skeletonic-stylus@3.0.0 --json | \  jq '.dist."npm-signature"' </code></pre> 
हस्ताक्षरित attestation tarball को ठीक उसी GitHub Actions रन से जोड़ती है जिसने इसे बनाया।
