सुलभता — v2.0.0 में WCAG 2.2

Translation note (2026-04-30). v2.0.0 adds RTL support and a refreshed 2026 framework comparison. The English source is the canonical reference while these translations catch up. See https://skeletonic.io/about/ · https://skeletonic.io/components/ · https://skeletonic.io/benchmarks/.

Skeletonic Stylus v2.0.0 WCAG 2.2 अनुरूपता को डिफ़ॉल्ट व्यवहार के रूप में शिप करती है, वैकल्पिक थीम के रूप में नहीं। यह पेज बताता है कि क्या अंतर्निहित है और बारीक नियंत्रण के लिए कौन से मिक्सिन उपलब्ध हैं।

आपको मुफ़्त में क्या मिलता है

WCAG 2.2 SC v2.0.0 क्या करती है कैसे सत्यापित करें
1.4.3 कंट्रास्ट (न्यूनतम) — AA <code>--cl-primary</code> और <code>--cl-secondary</code> को सफ़ेद के विरुद्ध ≥ 4.5:1 तक गहरा किया गया DevTools → contrast checker
1.4.11 गैर-टेक्स्ट कंट्रास्ट — AA फ़ॉर्म बॉर्डर, बटन, बैज सब ≥ 3:1 वही
2.4.7 फ़ोकस विज़िबल — AA हर फ़ोकस योग्य तत्व पर <code>:focus-visible</code> रिंग (अंधेरी पृष्ठभूमि पर पीला, हल्की पर नीला) पेज पर <code>Tab</code> करें
2.4.11 फ़ोकस अस्पष्ट नहीं — AA (2.2 में नया) स्टिकी हेडर की कम ऊँचाई + फ़ोकस scroll-margin स्टिकी हेडर के पार <code>Tab</code> करें
2.5.8 टार्गेट साइज़ — AA (2.2 में नया) बटन / लिंक: ≥ 24×24 CSS px हिट एरिया DevTools box model
1.4.12 टेक्स्ट स्पेसिंग — AA सभी तत्व उपयोगकर्ता line-height / letter-spacing ओवरराइड का सम्मान करते हैं DevTools में ओवरराइड करें
2.3.3 इंटरैक्शन से एनिमेशन — AAA सभी एनिमेशन क्लास <code>@media (prefers-reduced-motion: no-preference)</code> में लपेटी हैं OS-स्तर reduce-motion
1.4.10 Reflow — AA लेआउट 320 px पर बिना क्षैतिज स्क्रॉल के काम करता है DevTools संकीर्ण viewport
डार्क मोड <code>prefers-color-scheme: dark</code> स्वचालित रूप से टोकन बदलता है OS डार्क-मोड टॉगल

Stylus मिक्सिन जिन्हें आप सक्रिय कर सकते हैं

यदि आप सोर्स से कंपाइल करते हैं, तो निम्न मिक्सिन <code>src/stylus/utilities/mixins.styl</code> में उपलब्ध हैं:

मिक्सिन उपयोग
<code>focus-ring()</code> <code>:focus-visible</code> का सम्मान करने वाली उच्च-कंट्रास्ट फ़ोकस रिंग
<code>visually-hidden()</code> स्क्रीन-रीडर-ओनली टेक्स्ट जो फ़ोकस योग्य रहता है
<code>skip-link()</code> फ़ोकस पर दिखने वाला एंकर
<code>reduced-motion()</code> किसी भी ब्लॉक को <code>prefers-reduced-motion: no-preference</code> में लपेटता है
<code>forced-colors()</code> Windows High Contrast Mode के लिए समायोजन
<code>target-size(24px)</code> किसी भी क्लिक करने योग्य तत्व को न्यूनतम टैप टार्गेट तक पैड करता है

उदाहरण:

<code class="language-stylus">// कस्टम बटन पर मज़बूत फ़ोकस रिंग लागू करें .my-button focus-ring() target-size(28px) </code></pre> 
 
स्किप-लिंक हेल्पर
 
इसे <code><body></code> के अंदर सबसे पहले डालें:
 
<code class="language-html"><a href="#main-content" class="skip-link">मुख्य सामग्री पर जाएँ</a> </code></pre> 
यह क्लास कोर स्टाइलशीट में नहीं है (ताकि पेज वेट न बढ़े); यह 4-पंक्ति का स्निपेट है जो आप स्वयं बनाते हैं या शामिल <code>skip-link()</code> मिक्सिन इस्तेमाल करते हैं। यह साइट इसे इस्तेमाल करती है — पेज पर फ़ोकस करें और Tab दबाएँ, यह ऊपर-बाएँ दिखेगा।
 
 
अपने पेजों को सत्यापित करना
 
लाइब्रेरी <code>scripts/</code> के अंतर्गत एक <code>a11y-test.mjs</code> स्क्रिप्ट शिप करती है जो आपके द्वारा दिए गए हर URL पर axe-core चलाती है।
 
<code class="language-bash">node scripts/a11y-test.mjs https://example.com </code></pre> 
CI हर push पर <code>dist/index.html</code> शोकेस पेज पर यह स्क्रिप्ट चलाता है।
