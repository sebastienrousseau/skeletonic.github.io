v2.0.0 — 2026-04 (वर्तमान)

"रिलीज़-तैयारी" पास: a11y, आपूर्ति श्रृंखला, रिपॉज़िटरी स्वच्छता।

सुलभता (WCAG 2.2)

  • <code>$primary</code> गहरा किया <code>hsl(210, 100%, 42%)</code> पर, बटन / बैज / लिंक में सफ़ेद टेक्स्ट के विरुद्ध AA कंट्रास्ट के लिए।
  • <code>$secondary</code> गहरा किया <code>hsl(195, 100%, 33%)</code> पर।
  • हर इंटरैक्टिव तत्व पर focus-visible रिंग जोड़ी।
  • एनिमेशन मॉड्यूल के चारों ओर <code>@media (prefers-reduced-motion)</code> wrapper जोड़ा।
  • <code>prefers-color-scheme: dark</code> टोकन स्वैप जोड़ा।
  • WCAG 2.2 SC 2.5.8 पूरा करने के लिए target-size(24px) मिक्सिन जोड़ा।
  • स्टिकी हेडर के लिए focus-not-obscured scroll-margin हेल्पर जोड़े।

बिल्ड और आपूर्ति श्रृंखला

  • Cascade layers — हर ब्लॉक अब <code>@layer skeletonic.{reset,tokens,layout,elements,components,utilities}</code> में है।
  • npm tarball के हिस्से के रूप में CycloneDX SBOM जनरेट।
  • CI में <code>size-limit</code> बजट लागू: कोर स्टाइलशीट पर 8 KB gzipped सीमा।
  • CVE-2023-44270 (postcss line return) <code>pnpm.overrides</code> से पैच।
  • npm प्रकाशन वर्कफ़्लो पर Provenance + signing (<code>--provenance --access public</code>)।
  • lint config से संग्रहित <code>stylelint-a11y</code> प्लगइन हटाया।

रिपॉज़िटरी स्वच्छता और उपभोक्ता पैकेज

  • पुरानी <code>package/</code> डायरेक्ट्री हटाई; <code>dist/</code> अब उपभोक्ताओं के लिए एकमात्र सत्य स्रोत है।
  • v2.0.0 इंस्टॉल पथ दर्शाने के लिए README पुनर्लिखित।
  • <code>dist/</code> कमिट है; <code>debug/</code> जनरेट और gitignored है।
  • नया <code>.github/workflows/npm-publish.yml</code> टैग-संचालित।

बग फ़िक्स (P0)

  • <code>row $:after</code> parent-selector रिग्रेशन — <code>src/stylus/components/_grid.styl</code> में भटका <code>$</code> को <code>&</code> से बदला।
  • <code>.alternate</code> ने ग़लती से <code>animation-direction: reverse</code> लागू किया <code>alternate</code> के बजाय।
  • <code>.alert-*</code> नेमस्पेसिंग — <code>.alert.success</code> → <code>.alert.alert-success</code> state क्लास से टकराव रोकने के लिए।
