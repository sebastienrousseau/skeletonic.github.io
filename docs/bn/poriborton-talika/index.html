v2.0.0 — 2026-04 (বর্তমান)

"রিলিজ-রেডিনেস" পাস: a11y, সাপ্লাই চেইন, রিপো হাইজিন।

প্রবেশাধিকার (WCAG 2.2)

  • বাটন / ব্যাজ / লিংকে সাদা টেক্সটের বিপরীতে AA কনট্রাস্টের জন্য <code>$primary</code> গাঢ় করা হয়েছে <code>hsl(210, 100%, 42%)</code>-এ।
  • <code>$secondary</code> গাঢ় করা হয়েছে <code>hsl(195, 100%, 33%)</code>-এ।
  • প্রতিটি ইন্টারেক্টিভ এলিমেন্টে focus-visible রিং যোগ করা হয়েছে।
  • অ্যানিমেশন মডিউলে <code>@media (prefers-reduced-motion)</code> মোড়ক যোগ করা হয়েছে।
  • <code>prefers-color-scheme: dark</code> টোকেন সোয়াপ যোগ করা হয়েছে।
  • WCAG 2.2 SC 2.5.8 পূরণ করতে target-size(24px) মিক্সিন যোগ করা হয়েছে।
  • স্টিকি হেডারের জন্য focus-not-obscured scroll-margin সহায়ক যোগ করা হয়েছে।

বিল্ড ও সাপ্লাই চেইন

  • Cascade layers — প্রতিটি ব্লক এখন <code>@layer skeletonic.{reset,tokens,layout,elements,components,utilities}</code>-এ থাকে।
  • npm tarball-এর অংশ হিসেবে CycloneDX SBOM তৈরি।
  • CI-তে <code>size-limit</code> বাজেট বাধ্যতামূলক: মূল স্টাইলশিটে 8 KB gzipped সীমা।
  • CVE-2023-44270 (postcss line return) <code>pnpm.overrides</code> দিয়ে প্যাচড।
  • npm publish ওয়ার্কফ্লোতে Provenance + signing (<code>--provenance --access public</code>)।
  • লিন্ট কনফিগ থেকে আর্কাইভড <code>stylelint-a11y</code> প্লাগইন অপসারিত।

রিপো হাইজিন ও কনজিউমার প্যাকেজ

  • লেগ্যাসি <code>package/</code> ডিরেক্টরি অপসারিত; কনজিউমারদের জন্য <code>dist/</code> এখন একমাত্র সত্যের উৎস।
  • v2.0.0 ইনস্টল পাথ প্রতিফলিত করতে README পুনর্লিখিত।
  • <code>dist/</code> কমিটেড; <code>debug/</code> তৈরি হয় ও gitignored।
  • নতুন <code>.github/workflows/npm-publish.yml</code> ট্যাগ-চালিত।

বাগ ফিক্স (P0)

  • <code>row $:after</code> প্যারেন্ট-সিলেক্টর রিগ্রেশন — <code>src/stylus/components/_grid.styl</code>-এ বিচ্ছিন্ন <code>$</code> কে <code>&</code> দিয়ে প্রতিস্থাপিত।
  • <code>.alternate</code> ভুলবশত <code>alternate</code>-এর পরিবর্তে <code>animation-direction: reverse</code> প্রয়োগ করেছিল।
  • <code>.alert-*</code> নেমস্পেসিং — স্টেট ক্লাসের সাথে সংঘর্ষ এড়াতে <code>.alert.success</code> → <code>.alert.alert-success</code>।
