What's new in 2.0
 
Six 2026-baseline CSS features the library now ships natively.
 
  
 Feature Where it lives 
   
 OKLCH colour system every brand / status / grey token, dark-mode included 
 
 Native <code>@layer</code> <code>skeletonic.{base,layout,elements,components}</code> — drop unlayered overrides anywhere and they win 
 
 CSS Grid layout <code>.grid</code> + <code>.grid-cols-1..12</code> + <code>.col-span-1..12</code> 
 
 Container queries <code>.card</code> reflows to its parent's width, not the viewport's 
 
 View Transitions API <code>.view-transition-name-{root,header,main,footer,article,section}</code> 
 
 Scroll-driven animation <code>.scroll-timeline</code>, <code>.animate-on-scroll</code>

The Anatomy of Skeletonic
 
Six paths into the library. Pick what you need.
 
   
Get started
 
Install once. Theme in seconds. From CDN to Stylus pipeline.
    
Components
 
Buttons, alerts, badges, cards, forms, headers — every snippet copy-paste ready.
    
Palettes
 
Material, Tachyons and web-safe colour systems. Conformant out of the box.
    
Animations
 
Bounce, fade, pulse, shake, vanish & zoom — gated behind <code>prefers-reduced-motion</code>.
    
Accessibility & RTL
 
WCAG 2.2 AA. Focus rings. Skip links. Reduced motion. Dark mode. Logical-property RTL — no extra stylesheet.
    
Security
 
CycloneDX SBOM. npm provenance. Pinned dependencies. CVE-patched.

Built for the post-bundler web
 
Skeletonic exists for the parts of the web where Tailwind v4's Oxide pipeline is overkill: HTMX apps, Hotwire and Phoenix LiveView, Astro MPA, every Hugo / Eleventy / Shokunin SSG, server-rendered Laravel / Django / Rails templates, and AI-scaffolded HTML. One <code>&lt;link&gt;</code>, no JavaScript, no compile step, real RTL, real WCAG 2.2 AA. No surprises in production.
 
<code class="language-html"><link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@sebastienrousseau/skeletonic-stylus@3.0.0/css/core/skeletonic.min.css"> </code></pre>
