Sakerhet & leveranskedja

Prestanda

  • 45,7 KB minifierad · 8,3 KB gzippad · 6,9 KB brotli for det fullstandiga karn-stylesheetet.
  • Noll JavaScript — ren Stylus → ren CSS, ingen runtimekostnad.
  • Cascade-layered — overskrivningar vinner utan <code>!important</code>.
  • <code>size-limit</code>-budget tillampad i CI vid varje commit.

Prestanda ar en sakerhetsatgard. Varje byte som inte levereras ar en farre byte att granska, signera och verifiera.

CycloneDX SBOM

Varje publicerad tarball inkluderar en CycloneDX SBOM pa <code>dist/sbom.json</code>. Du kan verifiera ett nyinstallerat paket med:

<code class="language-bash">pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0 jq '.metadata.component.version' \  node_modules/@sebastienrousseau/skeletonic-stylus/dist/sbom.json # → "2.0.0" </code></pre> 
SBOM:en genereras med <code>cyclonedx-npm</code> under publiceringsarbetsfloden.
 
 
npm-proveniens
 
Den publicerade artefakten ar signerad med npm-paketproveniens.
 
Du kan verifiera den efter installation med:
 
<code class="language-bash">npm view @sebastienrousseau/skeletonic-stylus@3.0.0 --json | \  jq '.dist."npm-signature"' </code></pre> 
Den signerade attesteringen lankar tarballen tillbaka till den exakta GitHub Actions-korningen som producerade den.
