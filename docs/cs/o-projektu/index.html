Ve zkratce

Skeletonic Stylus je open-source knihovna Stylus CSS vytvorena pro pristupne, rychle a modularni stylovani rozhrani.

Vznikla v roce 2018 jako osobni experiment v dodavani minima CSS bez ztraty ergonomie skutecne komponentove knihovny. Po osmi letech zustavaji cile nezmeneny.

Co vam nabizi

Bleskove rychle

Navrhujte a prisposobujte responzivni rozhrani behem minut. Nativni CSS promenne, preddefinovane tridy, 12sloupcova mrizka pokryvajici kazdy semanticky HTML element.

Lehke

8,3 KB gzipped. Stranky se nacitaji rychleji. Kazdy zakladni stavebni blok zustava.

Responzivni design

Navrzeno pro desktop i mobil. Rozvrzeni se prizpusobi kazdemu zarizeni. Optimalizovano pro dotyk, semanticke HTML v cele strukture.

Pristupnost

WCAG 2.2 integrovano: focus-visible ohraniceni, AA kontrast, skip-link pomocnici, ovladani klavesnici, podpora omezeneho pohybu — zadny extra stylesheet, zadny <code>aria-*</code> boilerplate.

Knihovna komponent

Modularni CSS komponenty a Stylus mixiny. Tlacitka, formulare, karty, upozorneni, stitky, palety a animace — ciste, modularni, pripravene k pouziti.

Zdarma a open source

Navrzeno, vytvoreno a spravovano Sebastienem Rousseauem. Dualni licence pod MIT nebo Apache 2.0. Zadne poplatky, zadne licencni naklady, ani pro komercni pouziti.

Jak se srovnava

Jeden self-hosted stylesheet pokryva typografii, tlacitka, formulare, karty, tabulky, palety, animace a utilitni tridy. Zadny JavaScript. Zadny build krok. Zadne zavislosti na Bootstrap, Tailwind nebo Bulma.

Principy

  1. Pristupnost je zaklad, ne nadstavba. Soulad s WCAG 2.2 je integrovany do kazde komponenty, nikdy neni pripojeny jako „tema".
  2. Na bajtech zalezi. Jeden dodavany stylesheet by nemel vybuchnout vas rozpocet na velikost stranky. Strop 8 KB gzipped je vynucovan v CI.
  3. Kaskadove vrstvy porazily valky o specificitu. Cokoli prepiste s jistotou — zadne <code>!important</code>, zadne triky s poradim v DOM.
  4. Stylus je stale skvely. Strucny, expresivni a umoznuje knihovne zustat v ~3 000 citelnych radcich.
  5. Nuda je vlastnost. Zadne JS zavislosti. Zadna build magie. Zadne lamic prejmenovani. CSS tridy, ktere delaji presne to, co rikaji.
  6. Tema za par sekund. Nativni CSS vlastni vlastnosti pro barvy, odsazeni, typografii a zaobleni.
  7. Zabezpeceny dodavatelsky retezec. Podepsany npm provenance. Fixovane Dependabot aktualizace. CVE-2023-44270 opraveno pres overrides.

Verzovani & semver

Skeletonic Stylus se ridi Semantickym verzovanim 2.0.

Zmena Kdy Priklad
Major Odstraneni nebo prejmenovani verejne tridy, mixinu nebo tokenu 1.x → 2.0
Minor Pridani nove komponenty, mixinu nebo tokenu 1.1 → 1.2
Patch Opravy chyb, vylepseni pristupnosti, vykon, bezpecnost 1.1.6 → 2.0.0

Vsechny verejne nazvy trid, vsechny CSS vlastni vlastnosti a vsechny exportovane Stylus mixiny jsou soucasti verejneho API. Zpetne nekompatibilni zmena si zaslizi major bump a pruvodce migraci.
