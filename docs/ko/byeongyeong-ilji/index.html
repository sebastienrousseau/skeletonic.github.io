v2.0.0 — 2026-04 (현재)

"릴리스 준비" 패스: 접근성, 공급망, 저장소 정리.

접근성 (WCAG 2.2)

  • <code>$primary</code> 어둡게 조정 — 버튼 / 뱃지 / 링크에서 흰색 텍스트에 대한 AA 대비를 위해 <code>hsl(210, 100%, 42%)</code>로 변경.
  • <code>$secondary</code> 어둡게 조정 — <code>hsl(195, 100%, 33%)</code>로 변경.
  • 모든 인터랙티브 요소에 focus-visible 링 추가.
  • 애니메이션 모듈에 <code>@media (prefers-reduced-motion)</code> 래퍼 추가.
  • <code>prefers-color-scheme: dark</code> 토큰 전환 추가.
  • WCAG 2.2 SC 2.5.8을 충족하기 위한 target-size(24px) 믹스인 추가.
  • 고정 헤더를 위한 focus-not-obscured scroll-margin 도우미 추가.

빌드 & 공급망

  • 캐스케이드 레이어 — 모든 블록이 <code>@layer skeletonic.{reset,tokens,layout,elements,components,utilities}</code> 내에 위치.
  • CycloneDX SBOM — npm tarball의 일부로 생성.
  • <code>size-limit</code> 예산 — CI에서 적용: 코어 스타일시트 8 KB gzipped 상한선.
  • CVE-2023-44270 (postcss 줄바꿈) — <code>pnpm.overrides</code>를 통해 패치.
  • npm 게시 워크플로우에서 출처 증명 + 서명 (<code>--provenance --access public</code>).
  • 보관된 <code>stylelint-a11y</code> 플러그인을 린트 설정에서 제거.

저장소 정리 & 소비자 패키지

  • 레거시 <code>package/</code> 디렉토리 제거; <code>dist/</code>가 이제 소비자를 위한 단일 소스.
  • v2.0.0 설치 경로를 반영하여 README 재작성.
  • <code>dist/</code>는 커밋됨; <code>debug/</code>는 생성되며 gitignore 처리.
  • 새로운 <code>.github/workflows/npm-publish.yml</code>은 태그 기반.

버그 수정 (P0)

  • <code>row $:after</code> 부모 선택자 회귀 — <code>src/stylus/components/_grid.styl</code>에서 잘못된 <code>$</code>를 <code>&</code>로 교체.
  • <code>.alternate</code> — <code>animation-direction: reverse</code> 대신 올바르게 <code>alternate</code> 적용.
  • <code>.alert-*</code> 네임스페이스화 — <code>.alert.success</code> → <code>.alert.alert-success</code>로 변경하여 상태 클래스와의 충돌 방지.
