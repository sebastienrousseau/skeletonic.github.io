보안 & 공급망

성능

  • 38.8 KB 최소화 · 7.7 KB gzipped · 6.7 KB brotli (전체 코어 스타일시트 기준).
  • JavaScript 없음 — 순수 Stylus → 순수 CSS, 런타임 비용 없음.
  • 캐스케이드 레이어 — <code>!important</code> 없이 오버라이드가 적용됩니다.
  • <code>size-limit</code> 예산이 CI에서 매 커밋마다 적용됩니다.

성능은 보안 통제입니다. 전송하지 않는 모든 바이트는 감사, 서명 및 검증할 바이트가 하나 줄어드는 것입니다.

CycloneDX SBOM

모든 게시된 tarball에는 <code>dist/sbom.json</code>에 CycloneDX SBOM이 포함되어 있습니다. 새로 설치한 패키지를 다음과 같이 확인할 수 있습니다:

<code class="language-bash">pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0 jq '.metadata.component.version' \  node_modules/@sebastienrousseau/skeletonic-stylus/dist/sbom.json # → "2.0.0" </code></pre> 
SBOM은 게시 워크플로우 중 <code>cyclonedx-npm</code>으로 생성됩니다.
 
 
npm 출처 증명
 
게시된 산출물은 npm 패키지 출처 증명을 사용하여 서명됩니다.
 
설치 후 다음과 같이 확인할 수 있습니다:
 
<code class="language-bash">npm view @sebastienrousseau/skeletonic-stylus@3.0.0 --json | \  jq '.dist."npm-signature"' </code></pre> 
서명된 증명은 tarball을 해당 산출물을 생성한 정확한 GitHub Actions 실행에 연결합니다.
