뱃지
 
상태, 개수 또는 카테고리를 위한 소형 라벨입니다. 텍스트 크기가 고정되어 있어 뱃지가 주변 텍스트와 정렬됩니다.

접근성 참고. 뱃지는 기본적으로 장식용입니다. 뱃지가 유일한 신호(예: 읽지 않은 개수)를 전달하는 경우, 시각적으로 숨겨진 도우미로 감싸십시오: <code>읽지 않은 메시지 3개</code>.
 
 
 
피드백
 
방문자에게 무언가가 발생했거나 발생하려 한다는 것을 알려주는 표면입니다.
 
알림
 
시맨틱 의도를 가진 상태 메시지입니다. v2.0.0에서 모든 변형은 명시적으로 <code>.alert-{primary,secondary,info,success,warning,error}</code> 하에 네임스페이스화되어 변형 클래스가 페이지의 다른 상태 클래스와 충돌하지 않습니다.

접근성 참고. 즉각적인 주의가 필요한 메시지(오류, 경고)에는 <code>role="alert"</code>을, 긴급하지 않은 확인에는 <code>role="status"</code>를 사용하십시오. 둘 다 메시지가 나타나는 즉시 보조 기술에 노출됩니다.
