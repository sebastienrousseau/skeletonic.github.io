Bijdragen

Skeletonic Stylus is een open-sourceproject; bijdragen van elke omvang zijn welkom — van typecorrecties tot nieuwe componenten.

Snel starten

<code class="language-bash"># 1. Fork &amp; kloon git clone git@github.com:JOUW-GEBRUIKER/skeletonic-stylus.git cd skeletonic-stylus # 2. Installeren (pnpm via corepack) corepack enable pnpm install # 3. Bouwen pnpm run build # volledige pipeline (stylus → prettier → stylelint → autoprefixer → csso)  # 4. Linten &amp; testen pnpm run lint node scripts/a11y-test.mjs </code></pre> 
 
Conventies
 
     
  • Branchnamen: <code>feat/korte-omschrijving</code>, <code>fix/korte-omschrijving</code>, <code>docs/korte-omschrijving</code>.
    •  
  • Commits: Conventional Commits. Alle commits worden ondertekend.
    •  
  • Stylus: 4-spatie-inspringing, geen puntkomma's, voorkeur voor <code>$variables</code> boven magische getallen, elke publieke klasse bevindt zich in een cascade layer.
    •  
  • Toegankelijkheid: elke nieuwe component moet aantoonbaar voldoen aan WCAG 2.2 AA; voer <code>node scripts/a11y-test.mjs</code> uit tegen de showcase voordat je een PR opent.
    •  
  • Groottebudget: het kernstylesheet moet onder 8 KB gzipped blijven. Als je wijziging dit overschrijdt, onderbouw het in de PR.
    •  
 
 
Pull requests
 
     
  1. Open eerst een issue voor alles wat niet triviaal is — bespaart herwerk.
    2.  
  2. Houd PR's gefocust: één logische wijziging per PR.
    3.  
  3. Werk de <code>CHANGELOG.md</code> bij onder "Unreleased".
    4.  
  4. Zorg dat CI groen is voordat je een review aanvraagt.
    5.  
  5. Squash-merge is de standaard; commitberichten worden opgeschoond bij merge.
    6.
