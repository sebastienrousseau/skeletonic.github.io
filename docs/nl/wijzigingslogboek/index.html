v2.0.0 — 2026-04 (huidig)

De "release-gereedheid"-controle: a11y, toeleveringsketen, repositoryhygiëne.

Toegankelijkheid (WCAG 2.2)

  • <code>$primary</code> donkerder gemaakt naar <code>hsl(210, 100%, 42%)</code> voor AA-contrast tegen witte tekst in knoppen / badges / links.
  • <code>$secondary</code> donkerder gemaakt naar <code>hsl(195, 100%, 33%)</code>.
  • focus-visible-ringen toegevoegd op elk interactief element.
  • <code>@media (prefers-reduced-motion)</code>-wrapper toegevoegd rond de animatiemodule.
  • <code>prefers-color-scheme: dark</code> tokenwissel toegevoegd.
  • target-size(24px) mixin toegevoegd om te voldoen aan WCAG 2.2 SC 2.5.8.
  • focus-not-obscured scroll-margin helpers toegevoegd voor vaste headers.

Build & toeleveringsketen

  • Cascade layers — elk blok bevindt zich nu in <code>@layer skeletonic.{reset,tokens,layout,elements,components,utilities}</code>.
  • CycloneDX SBOM gegenereerd als onderdeel van het npm-tarball.
  • <code>size-limit</code>-budgetten afgedwongen in CI: 8 KB gzipped-plafond op het kernstylesheet.
  • CVE-2023-44270 (postcss regelterugloop) gepatcht via <code>pnpm.overrides</code>.
  • Herkomst + ondertekening in de npm-publicatieworkflow (<code>--provenance --access public</code>).
  • Verouderde <code>stylelint-a11y</code>-plugin verwijderd uit de lintconfiguratie.

Repositoryhygiëne & consumentenpakket

  • Verouderde <code>package/</code>-map verwijderd; <code>dist/</code> is nu de enige bron van waarheid voor gebruikers.
  • README herschreven om v2.0.0-installatiepaden te reflecteren.
  • <code>dist/</code> wordt gecommit; <code>debug/</code> wordt gegenereerd en gitignored.
  • Nieuwe <code>.github/workflows/npm-publish.yml</code> is tag-gestuurd.

Bugfixes (P0)

  • <code>row $:after</code> parent-selector-regressie — verdwaalde <code>$</code> vervangen door <code>&</code> in <code>src/stylus/components/_grid.styl</code>.
  • <code>.alternate</code> paste per ongeluk <code>animation-direction: reverse</code> toe in plaats van <code>alternate</code>.
  • <code>.alert-*</code>-naamgeving — <code>.alert.success</code> → <code>.alert.alert-success</code> om botsingen met statusklassen te voorkomen.
