Seguridad & supply chain

Performance

  • 38.8 KB minified · 7.7 KB gzipped · 6.7 KB brotli para sa buong core stylesheet.
  • Walang JavaScript — purong Stylus → purong CSS, walang runtime cost.
  • Cascade-layered — nananalo ang mga override nang walang <code>!important</code>.
  • <code>size-limit</code> budget na ipinatutupad sa CI sa bawat commit.

Ang performance ay isang security control. Bawat byte na hindi ipinapadala ay isang byte na mas kaunti ang kailangang i-audit, lagdaan, at i-verify.

CycloneDX SBOM

Bawat na-publish na tarball ay may kasamang CycloneDX SBOM sa <code>dist/sbom.json</code>. Maaari mong i-verify ang isang bagong na-install na package gamit ang:

<code class="language-bash">pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0 jq '.metadata.component.version' \  node_modules/@sebastienrousseau/skeletonic-stylus/dist/sbom.json # → "2.0.0" </code></pre> 
Ang SBOM ay ginagawa gamit ang <code>cyclonedx-npm</code> sa panahon ng publish workflow.
 
 
npm provenance
 
Ang na-publish na artefact ay nilalagdaan gamit ang npm package provenance.
 
Maaari mo itong i-verify pagkatapos ng pag-install gamit ang:
 
<code class="language-bash">npm view @sebastienrousseau/skeletonic-stylus@3.0.0 --json | \  jq '.dist."npm-signature"' </code></pre> 
Ikinokonekta ng signed attestation ang tarball pabalik sa eksaktong GitHub Actions run na gumawa nito.
