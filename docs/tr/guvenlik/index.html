CycloneDX SBOM

Yayinlanan her tarball, <code>dist/sbom.json</code> konumunda bir CycloneDX SBOM icerir. Yeni kurulan bir paketi soyle dogrulayabilirsiniz:

<code class="language-bash">pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0 jq '.metadata.component.version' \  node_modules/@sebastienrousseau/skeletonic-stylus/dist/sbom.json # → "2.0.0" </code></pre> 
SBOM, yayinlama is akisi sirasinda <code>cyclonedx-npm</code> ile olusturulur.
 
 
npm provenance
 
Yayinlanan urun, npm paket provenance kullanilarak imzalanir.
 
Kurulumdan sonra soyle dogrulayabilirsiniz:
 
<code class="language-bash">npm view @sebastienrousseau/skeletonic-stylus@3.0.0 --json | \  jq '.dist."npm-signature"' </code></pre> 
Imzali onay, tarball'i onu ureten GitHub Actions calistirmasina geri baglar.
