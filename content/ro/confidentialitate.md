## Rezumat

> **skeletonic.com nu setează cookie-uri de urmărire și nu rulează
> tag-uri de analiză de la terți.** Site-ul este un set static de HTML,
> CSS și un singur fișier service-worker. Nicio cerere pe care o faci
> nu este înregistrată dincolo de jurnalele standard de acces GitHub
> Pages.

<hr class="hr-text" data-content="Detalii">

## Ce date sunt colectate

1. **Jurnale de acces GitHub Pages.** Când încarci orice pagină, GitHub
   înregistrează adresa ta IP, URL-ul cererii și ora. Se aplică politica
   de confidențialitate GitHub — vezi
   [docs.github.com/en/site-policy](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
2. **Formularul de contact.** Dacă trimiți formularul de pe `/ro/contact/`,
   datele trec prin [Formspree](https://formspree.io), care le
   redirecționează către email-ul maintainer-ului. Se aplică politica de
   confidențialitate Formspree.
3. **Service worker.** Scriptul `sw.js` memorează în cache răspunsuri
   HTML, CSS, JS și imagini **local în browser-ul tău**, pentru ca site-ul
   să funcționeze offline. Nimic nu este trimis nicăieri.

## Ce *nu* se colectează

- Fără Google Analytics, Plausible, Fathom sau alt tag de analiză.
- Fără cookie-uri de niciun fel. Site-ul nu setează niciunul.
- Fără local storage sau IndexedDB dincolo de cache-ul service-worker.
- Fără fingerprinting, rețele publicitare sau trackere terțe.

## Drepturile tale

Dacă ai folosit formularul de contact și dorești ștergerea mesajului
tău, trimite-mi un email de la adresa cu care ai trimis și îl voi șterge
în 30 de zile.
