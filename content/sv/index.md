Tillganglig CSS pa **under 8&nbsp;KB gzippat**. WCAG&nbsp;2.2-klart.
Cascade-layered. Noll JavaScript. Lagg till pa vilken sida som helst.

```bash
pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0
```
