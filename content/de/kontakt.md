Der schnellste Weg zur Kontaktaufnahme ist das untenstehende Formular — es wird direkt über [Formspree](https://formspree.io) zugestellt. Für alles, was Code betrifft, bitte ein Issue auf
[GitHub](https://github.com/sebastienrousseau/skeletonic-stylus/issues) eröffnen, damit die Konversation öffentlich und durchsuchbar bleibt.

Für **Sicherheitsmeldungen** die [Sicherheitsseite](/de/sicherheit/) beachten — für Schwachstellen bitte keine öffentlichen Issues anlegen.
