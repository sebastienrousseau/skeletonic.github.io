## Ni ṣoki

> **skeletonic.com ko ṣeto awọn kuki ilepa ati pe ko ṣiṣẹ ami itẹle
> ẹnikẹta.** Aaye yii jẹ eto HTML, CSS, ati faili service-worker kan
> ti o duro ṣinṣin. Ko si ibeere ti o ṣe ti a kọ silẹ ju awọn akọọlẹ
> wiwọle GitHub Pages lọ.

<hr class="hr-text" data-content="Awọn alaye">

## Data wo ni a gba

1. **Awọn akọọlẹ wiwọle GitHub Pages.** Nigba ti o ba gba oju-iwe
   eyikeyi, GitHub kọ adirẹsi IP rẹ, URL ibeere, ati akoko silẹ.
   Eto imulo asiri GitHub kan — wo
   [docs.github.com/en/site-policy](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
2. **Fọọmu olubasọrọ.** Ti o ba fi fọọmu ranṣẹ lori `/yo/kan-si-wa/`,
   data naa kọja nipasẹ [Formspree](https://formspree.io), ti o firanṣẹ
   si imeeli olutọju. Eto imulo asiri Formspree kan.
3. **Service worker.** Iwe afọwọkọ `sw.js` fi awọn idahun HTML, CSS,
   JS, ati aworan pamọ **ni agbegbe ninu aṣawakiri rẹ** nitorinaa aaye
   naa ṣiṣẹ ni alaisiasopọ. Ko si ohun ti a firanṣẹ si ibi kankan.

## Ohun ti a *ko* gba

- Ko si Google Analytics, Plausible, Fathom, tabi ami itẹle miiran.
- Ko si awọn kuki iru eyikeyi. Aaye naa ko ṣeto kankan.
- Ko si ibi-ipamọ agbegbe tabi IndexedDB ju kaṣi service-worker lọ.
- Ko si iṣe idanimọ, awọn nẹtiwọọki ipolowo, tabi awọn oluṣeto ẹnikẹta.
