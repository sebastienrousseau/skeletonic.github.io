## Ni ṣoki

**Skeletonic Stylus** jẹ ile-ikawe CSS [Stylus](https://stylus-lang.com)
orisun-ṣiṣi fun aṣa UI ti a le wọle si, ti o yara, ti o ni modulu.

A bi i ni ọdun 2018 gẹgẹbi idanwo ti ara ẹni ninu **fifiranṣẹ CSS ti
o kere** laisi fifun awọn ọna iṣẹ ti ile-ikawe paati gidi silẹ. Lẹhin
ọdun mẹjọ, ibi-afẹde naa ko yipada.

## Bawo ni o ṣe fi wewe

Iwe-aṣa ti ara ẹni kan bo iwe-kikọ, awọn bọtini, awọn fọọmu, awọn
kaadi, awọn tabili, awọn palẹti, awọn ere idasọnu ati awọn kilasi
iwulo. JavaScript kankan ko si. Ko si igbesẹ ikọ ti a beere. Ko si awọn
igbarale ẹlẹgbẹ lori Bootstrap, Tailwind tabi Bulma.

| Ẹya | Skeletonic Stylus | Bootstrap 5 | Tailwind CSS | Bulma |
|---|---|---|---|---|
| Iwọn gzipped | **7.7&nbsp;KB** | ~30&nbsp;KB | ~10&nbsp;KB (varies) | ~30&nbsp;KB |
| Ibamu WCAG 2.2 | **Ti a kọ sinu** | Apakan | Afọwọṣe | Apakan |
| Awọn ipele cascade | **Bẹẹni (`@layer`)** | Rara | Rara | Rara |
| Ipo dudu | **`prefers-color-scheme`** | Yiyan wọle | Ipilẹ kilasi | Yiyan wọle |
| JavaScript nilo | **Rara** | Bẹẹni (Popper) | Rara | Rara |
| CycloneDX SBOM | **Bẹẹni** | Rara | Rara | Rara |

| Iwe-aṣẹ | MIT tabi Apache 2.0 | MIT | MIT | MIT |

## Awọn ilana

1. **Irayẹ-si ni ipilẹ, kii ṣe oke.** Ibamu WCAG 2.2 ti a fi sinu
   gbogbo paati, a ko fi kun lẹhin bi "aṣa" kan.
2. **Awọn baiti ṣe pataki.** Iwe-aṣa kan ti a firanṣẹ ko yẹ ki o
   bọ isuna iwuwo oju-iwe rẹ. Opin 8&nbsp;KB gzipped ni a fi ipa mu
   ninu CI.
3. **Awọn ipele cascade bori ogun specificity.** Ṣe atunṣe ohunkohun
   pẹlu igboya — ko si `!important`, ko si awọn ẹtan aṣẹ-DOM.
4. **Stylus si dara.** Kukuru, ifarahan, o si jẹ ki ile-ikawe wa ninu
   ~3,000 awọn ila ti a le ka.
5. **Aibikita jẹ ẹya.** Ko si awọn igbarale JS. Ko si idan akoko-ikọ.
   Ko si awọn iyipada orukọ ti o fọ. Awọn kilasi CSS ti o ṣe ohun ti
   wọn sọ gangan.
6. **Ti a le ṣe aṣa ni iṣẹju-aaya.** Awọn ohun-ini aṣa CSS abinibi
   fun awọn awọ, aaye, iru ati radii.
7. **Ẹwọn-ipese ti a fi okun mu.** Ẹri npm ti a fọwọsi. Awọn imudojuiwọn
   Dependabot ti a fi idi mulẹ. CVE-2023-44270 ti a ṣe atunṣe nipasẹ
   overrides.

## Ẹya ati semver

Skeletonic Stylus tẹle [Semantic Versioning 2.0](https://semver.org).

| Ilọsiwaju | Nigba ti | Apẹẹrẹ |
|---|---|---|
| **Pataki** | Yiyọ tabi tunlorukọ kilasi gbogbo eniyan, adalu, tabi ami | 1.x → 2.0 |
| **Kekere** | Fifikun paati tuntun, adalu, tabi ami | 1.1 → 1.2 |
| **Atunṣe** | Awọn atunṣe aṣiṣe, imudara a11y, iṣẹ-ṣiṣe, aabo | 1.1.6 → 2.0.0 |

Gbogbo orukọ kilasi gbogbo eniyan, gbogbo awọn ohun-ini aṣa CSS, ati
gbogbo awọn adalu Stylus ti a kojade jẹ apakan ti API gbogbo eniyan.
Iyipada ti o fọ nkan ni ere ilọsiwaju pataki ati itọsọna iṣiwa.
