## In sintesi

> **skeletonic.com non imposta cookie di tracciamento e non esegue tag
> di analisi di terze parti.** Il sito e un insieme statico di HTML, CSS
> e un singolo file service-worker. Nessuna richiesta viene registrata
> oltre ai log di accesso standard di GitHub Pages.

<hr class="hr-text" data-content="Dettagli">

## Quali dati vengono raccolti

1. **Log di accesso di GitHub Pages.** Quando carichi una pagina, GitHub
   registra il tuo indirizzo IP, l'URL della richiesta e l'orario. Si
   applica l'informativa sulla privacy di GitHub — vedi
   [docs.github.com/en/site-policy](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
2. **Il modulo di contatto.** Se invii il modulo su `/it/contatti/`, i
   dati passano attraverso [Formspree](https://formspree.io), che li
   inoltra all'email del maintainer. Si applica l'informativa sulla
   privacy di Formspree.
3. **Service worker.** Lo script `sw.js` memorizza nella cache risposte
   HTML, CSS, JS e immagini **localmente nel tuo browser** cosi il sito
   funziona offline. Nulla viene inviato da nessuna parte.

## Cosa *non* viene raccolto

- Google Analytics, Plausible, Fathom o qualsiasi altro tag di analisi.
- Cookie di qualsiasi tipo. Il sito non ne imposta.
- Local storage o IndexedDB oltre alla cache del service worker.
- Fingerprinting, reti pubblicitarie o tracker di terze parti.

## I tuoi diritti

Se hai usato il modulo di contatto e desideri che il tuo messaggio venga cancellato, inviami un'email dall'indirizzo con cui hai effettuato l'invio e lo eliminero entro 30 giorni.
