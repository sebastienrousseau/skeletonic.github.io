## Коротко

> **skeletonic.com не встановлює відстежувальних cookie та не використовує
> сторонніх аналітичних тегів.** Сайт — це статичний набір HTML, CSS та
> один файл service worker. Жоден ваш запит не журналюється поза
> стандартними журналами доступу GitHub Pages.

<hr class="hr-text" data-content="Деталі">

## Які дані збираються

1. **Журнали доступу GitHub Pages.** При завантаженні будь-якої сторінки
   GitHub фіксує вашу IP-адресу, URL запиту та час. Застосовується
   політика конфіденційності GitHub — дивіться
   [docs.github.com/en/site-policy](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
2. **Контактна форма.** Якщо ви надсилаєте форму на `/uk/kontakt/`, дані
   проходять через [Formspree](https://formspree.io), який пересилає їх
   на електронну пошту мейнтейнера. Застосовується політика
   конфіденційності Formspree.
3. **Service worker.** Скрипт `sw.js` кешує HTML, CSS, JS та зображення
   **локально у вашому браузері**, щоб сайт працював офлайн. Нікуди
   нічого не надсилається.

## Що *не* збирається

- Google Analytics, Plausible, Fathom або будь-який інший аналітичний тег.
- Cookie будь-якого виду. Сайт не встановлює жодного.
- Local storage або IndexedDB, окрім кешу service worker.
- Фінгерпринтинг, рекламні мережі або сторонні трекери.
