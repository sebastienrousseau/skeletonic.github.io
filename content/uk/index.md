Доступний CSS **менше ніж 8&nbsp;КБ gzip**. Відповідає WCAG&nbsp;2.2.
Каскадні шари. Нуль JavaScript. Підключайте до будь-якої сторінки.

```bash
pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0
```
