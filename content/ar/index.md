CSS سهل الوصول بحجم **أقل من 8&nbsp;كيلوبايت مضغوط**. متوافق مع WCAG&nbsp;2.2.
يعتمد على طبقات التسلسل. بدون JavaScript. أضفه إلى أي صفحة مباشرة.

```bash
pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0
```
