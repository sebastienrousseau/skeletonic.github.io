アクセシブルな CSS を **gzip圧縮で8&nbsp;KB未満** で実現。WCAG&nbsp;2.2 対応。
カスケードレイヤー採用。JavaScript 不要。どのページにもすぐに導入できます。

```bash
pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0
```
