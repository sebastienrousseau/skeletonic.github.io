無障礙 CSS，**gzip 後不到 8&nbsp;KB**。符合 WCAG&nbsp;2.2 標準。
級聯層架構。零 JavaScript。即插即用。

```bash
pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0
```
