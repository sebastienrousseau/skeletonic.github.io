CSS accessible en **moins de 8 Ko gzippé**. Conforme WCAG 2.2.
Organisé en couches de cascade. Zéro JavaScript. À intégrer dans
n'importe quelle page.

```bash
pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0
```
