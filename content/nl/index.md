Toegankelijke CSS in **minder dan 8&nbsp;KB gzipped**. WCAG&nbsp;2.2 klaar.
Cascade-layered. Geen JavaScript. Direct in elke pagina te gebruiken.

```bash
pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0
```
