## בקיצור

> **skeletonic.com אינה מגדירה עוגיות מעקב ואינה מפעילה תג
> אנליטיקה של צד שלישי.** האתר הוא סט סטטי של HTML, CSS וקובץ
> service-worker יחיד. שום בקשה שאתם מבצעים לא נרשמת מעבר ליומני
> הגישה הסטנדרטיים של GitHub Pages.

<hr class="hr-text" data-content="פרטים">

## אילו נתונים נאספים

1. **יומני גישה של GitHub Pages.** כשאתם טוענים דף כלשהו, GitHub
   מתעדת את כתובת ה-IP שלכם, את URL הבקשה ואת הזמן. מדיניות
   הפרטיות של GitHub חלה — ראו
   [docs.github.com/en/site-policy](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
2. **טופס יצירת הקשר.** אם תשלחו את הטופס ב-`/he/kesher/`,
   הנתונים עוברים דרך [Formspree](https://formspree.io), שמעבירה
   אותם לדואר האלקטרוני של המתחזק. מדיניות הפרטיות של Formspree
   חלה.
3. **Service worker.** סקריפט `sw.js` שומר במטמון תגובות HTML, CSS,
   JS ותמונות **מקומית בדפדפן שלכם** כדי שהאתר יעבוד במצב לא
   מקוון. שום דבר לא נשלח לשום מקום.

## מה *לא* נאסף

- Google Analytics, Plausible, Fathom או כל תג אנליטיקה אחר.
- עוגיות מכל סוג. האתר אינו מגדיר אף אחת.
- Local storage או IndexedDB מעבר למטמון ה-service-worker.
- טביעת אצבע, רשתות פרסום או עוקבי צד שלישי.

## הזכויות שלכם

אם השתמשתם בטופס יצירת הקשר וברצונכם שההודעה שלכם תימחק, שלחו
לי דואר אלקטרוני מהכתובת ממנה שלחתם ואמחק אותה תוך 30 יום.
