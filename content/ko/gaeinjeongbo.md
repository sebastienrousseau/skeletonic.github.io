## 요약

> **skeletonic.com는 추적 쿠키를 설정하지 않으며 서드파티 분석 태그를 실행하지 않습니다.** 이 사이트는 HTML, CSS 및 단일 서비스 워커 파일로 구성된 정적 사이트입니다. 사용자의 요청은 표준 GitHub Pages 접속 로그 외에 기록되지 않습니다.

<hr class="hr-text" data-content="세부 사항">

## 수집하는 데이터

1. **GitHub Pages 접속 로그.** 페이지를 로드하면 GitHub이 IP 주소, 요청 URL 및 시간을 기록합니다. GitHub의 개인정보 보호정책이 적용됩니다 —
   [docs.github.com/en/site-policy](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)를 참조하십시오.
2. **문의 양식.** `/contact/`의 양식을 제출하면 데이터가 [Formspree](https://formspree.io)를 통해 유지관리자의 이메일로 전달됩니다. Formspree의 개인정보 보호정책이 적용됩니다.
3. **서비스 워커.** `sw.js` 스크립트는 HTML, CSS, JS 및 이미지 응답을 **브라우저에 로컬로 캐시**하여 사이트가 오프라인에서도 작동하도록 합니다. 어떤 데이터도 외부로 전송되지 않습니다.

## 수집하지 *않는* 데이터

- Google Analytics, Plausible, Fathom 또는 기타 분석 태그 없음.
- 어떤 종류의 쿠키도 없음. 사이트는 쿠키를 설정하지 않습니다.
- 서비스 워커 캐시 외의 로컬 스토리지 또는 IndexedDB 없음.
- 핑거프린팅, 광고 네트워크 또는 서드파티 추적기 없음.
