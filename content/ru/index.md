Доступный CSS — **менее 8&nbsp;КБ в gzip**. Соответствует WCAG&nbsp;2.2.
Каскадные слои. Без JavaScript. Подключите к любой странице.

```bash
pnpm add @sebastienrousseau/skeletonic-stylus@3.0.0
```
