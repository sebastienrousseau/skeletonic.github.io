## Ringkasan

> **skeletonic.com tidak memasang cookie pelacakan dan tidak menjalankan tag analitik pihak ketiga.** Situs ini adalah kumpulan statis HTML, CSS, dan satu file service worker. Tidak ada permintaan yang Anda buat yang dicatat selain log akses standar GitHub Pages.

<hr class="hr-text" data-content="Detail">

## Data apa yang dikumpulkan

1. **Log akses GitHub Pages.** Saat Anda memuat halaman mana pun, GitHub mencatat alamat IP Anda, URL permintaan, dan waktunya. Kebijakan privasi GitHub berlaku — lihat
   [docs.github.com/en/site-policy](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
2. **Formulir kontak.** Jika Anda mengirimkan formulir di `/id/kontak/`, data dikirim melalui [Formspree](https://formspree.io), yang meneruskannya ke email pengelola. Kebijakan privasi Formspree berlaku.
3. **Service worker.** Skrip `sw.js` menyimpan cache respons HTML, CSS, JS, dan gambar **secara lokal di browser Anda** sehingga situs berfungsi offline. Tidak ada data yang dikirim ke mana pun.

## Yang *tidak* dikumpulkan

- Google Analytics, Plausible, Fathom, atau tag analitik lainnya.
- Cookie apa pun. Situs ini tidak memasang cookie.
- Local storage atau IndexedDB selain cache service worker.
- Fingerprinting, jaringan iklan, atau pelacak pihak ketiga.

## Hak Anda

Jika Anda telah menggunakan formulir kontak dan ingin pesan Anda dihapus, kirim email dari alamat yang Anda gunakan saat mengirimkan dan saya akan menghapusnya dalam 30 hari.
